## 使用

在旧版主清单点击“退出程序”，等待进程退出，再双击项目 [启动聚合平台.cmd](../启动聚合平台.cmd)。关闭窗口会隐藏到托盘，启动入口会复用仍运行的实例，因此关闭窗口后再次双击不能切换版本。

在左侧打开中国大学 MOOC 平台管理，点击“连接平台”，进入官方 `/member/login.htm` 登录表单；手机号、邮箱、微信登录、验证码和扫码由用户完成。已有 Cookie 默认复用，明确过期时引导重新登录。登录确认后保存最新 Cookie 并列出课程，勾选后点击“保存选择并采集”，任务进入统一清单；“查看全部任务”清除平台、状态和搜索筛选。

任务保存官方状态、状态依据、开始与截止时间、成绩和具体任务入口。缺少提交依据时显示“待核对”；缺少任务截止时间时显示“平台未提供”。优先级按统一规则计算，手动修改字段和状态优先。

点击任务名称或“打开官方任务”在系统浏览器打开对应官方入口。系统浏览器使用自己的登录状态，可能需要官网登录或继续跳转；最终任务页面仍需核对，作答与提交由用户在官网完成。

平台管理支持按开课期选择需要采集和提醒的课程，同名课程不同开课期分别列出。新安装与旧配置迁移后均需确认选择，新增开课期不会自动选中。未选课程停止采集和提醒，历史任务保留。“刷新课程列表”只更新目录；本次刷新失败的结果和错误码独立保存，不会把旧任务同步成功当作本次刷新成功。开启自动同步后，启动时及每 30 分钟更新已选课程。

## 本轮修复

- 官方个人中心脚本会从 `/home.htm` 跳转到带 `userId` 的同一路径，旧版把首个 `ConnectionAborted` 当作网络失败。修复版跟踪最新导航，在当前页面出现确认的账号身份后读取，不等待统计、图片或后续阻塞脚本完成。新文档标记与地址、导航编号共同校验，未完成解析且没有身份时继续等待。
- 页面统计 Cookie 随页面加载变化，不能作为切换账号的依据；真正的登录 Cookie 变化仍会中止旧请求。统计 Cookie 中包含逗号的值按浏览器原值和作用域发送，避免 `CookieContainer` 拒绝有效浏览器 Cookie。
- 公开课程 DTO 缺少学生当前提交记录，改为官方已选课学生使用的 `getLastLearnedMocTermDto.rpc`，解析其 `result.mocTermDto`。未知结构不回退为“没有任务”。
- 官方旧考试卡对明确返回 null 的 `type` 生成 `examType=null`；保留这个原始参数，缺失或非法类型仍不猜测入口。
- 浏览器、个人中心、课程读取和结果保存的异常阶段写入同步详情。官方登录跳转显示 `MOOC001`，不会再统一归为网络错误。

- 登录入口直接使用官方登录页和官网 base64 返回路径；正常导航中断不报加载失败。同步结果保持可见，晚到的页面加载提示不覆盖它。
- 22:25 独立只读 WebView 登录检查确认页面 HTTP 200、官方密码输入框和验证 iframe 可加载，约 10 秒达到完整就绪。未点击或提交认证，未写正式库或归档。

## 请求与会话

后台只读请求以下元数据接口：

| 接口 | 参数 | 用途 |
| --- | --- | --- |
| `/web/j/learnerCourseRpcBean.getMyLearnedCoursePanelList.rpc` | `type=30, psize=8, courseType=1, p=页码` | 我的课程，含 MOOC 和 SPOC |
| `/web/j/courseBean.getLastLearnedMocTermDto.rpc` | `termId` | 学生课程任务与个人状态 |
| `/web/j/courseBean.getNewExamList.rpc` | `termId` | 新版考试元数据 |

请求使用官方 profile 中的 `NTESSTUDYSI` 做会话校验，不生成替代值。不请求会启动考试或读取题卷的 `mocExamBean.getPaper.rpc`，不答题或提交。每轮最多 100 页、800 门课程、1,200 次元数据请求；单响应最多 4 MB，请求超时 25 秒，默认间隔 180 毫秒。未知分页、限流和上限显示部分覆盖并保留已有任务。

独立 profile 为 `.local/webview-profile-mooc`。Cookie 用 Windows DPAPI 当前用户加密保存到任务库的 `platform_sessions` 表，每个平台只维护最新会话；旧 `.local/sessions/mooc.bin` 兼容迁移。保留 Cookie 原有效期与临时属性，不另设固定 30 天期限。HTTP 续期和删除写回同一 profile 与仓库，旧响应不能覆盖新登录。官方确认失效时保存过期标记，防止旧文件重新恢复；重登成功后覆盖旧 Cookie。“重新连接”只清除该平台会话并保留任务，完整退出先停止并等待请求再保存会话。

## 任务入口

MOOC 使用 `/learn/学校简称-课程号?tid=学期号`，SPOC 使用 `/spoc/learn/学校简称-课程号?tid=学期号`。

| 类型 | 官方片段路由 |
| --- | --- |
| 作业 | `#/learn/hw?id=...` |
| 编程作业 | `#/learn/ojhw?id=...` |
| 测验 | `#/learn/quiz?id=...` |
| 客观题考试 | `#/learn/examObject?eid=...&id=...&examType=...` |
| 主观题考试 | `#/learn/examSubjective?eid=...&id=...&examType=...` |
| 编程考试 | `#/learn/examOj?eid=...&id=...&examType=...` |
| 新版考试 | `#/learn/newExamAgreement?eid=...` |

课程、学期、任务类型、任务编号及考试编号均校验，链接加密保存。路由依据来自官方课程页面与公开脚本；最终系统浏览器的页面显示仍需真实点击核对。
