# 作业聚合平台问题汇总与改进进展

更新日期：2026-11-12。本轮交付 Android **1.1.4 登录修复测试版**（内部版本号 6），承接 1.1.3 的任务跳转和清单改进，专项修复学堂在线 XT001、U 校园短期掉登录及智慧树会话读取路径。GitHub 正式版本仍为 1.1.2，Windows 安装包仍为已发布的 1.1.2；共享源码的本轮改进已通过桌面回归，但尚未打入新的 Windows 安装包。

测试包已在独立 Android 15 模拟器中安装，使用合成账号、课程和响应验证。真实手机暂不可连接，因此“隔离检查通过”不代表九个平台均已通过真实账号验收。

## 后续改善顺序与验收办法

1. **真机跑通一门课的完整流程。** 应用内官方登录 → 账号确认 → 读取目录 → 本人选课 → 任务进入首页 → 跳转官方 App／网页 → 本人处理 → 返回刷新。逐项对照课程、状态、截止和入口；官网目录读取失败与账号失效分别提示。
2. **补齐会造成漏办的任务阶段和采集缺口。** 优先 MOOC／智慧树互评、智慧树共享作业分页与特殊类型；每个阶段保留独立的可信日期和官网状态。提交成功不能推定互评已完成。
3. **完成 UAI 的最小纵向接入。** 用已登录学生样本确认班级／课程／任务 ID、列表分页、截止、状态与任务入口，再接入统一选课和任务库；在这些证据齐全前继续明确显示概要预览。
4. **改善新鲜度与提醒的可观察性。** 恢复前台时按平台新鲜度补同步，失败退避；后续增加系统允许的后台最佳努力采集。用断网恢复、锁屏、Doze、重启和关闭通知验收，显示真实同步时间，不承诺后台准点。
5. **修复站点和会话差异。** 手机支持雨课堂标准／专业站点一致传入登录及采集；完善 PTA 失效归档与桌面关窗保存。学校名单未导入或换账号时提供课程对账入口。
6. **再做元数据备份、日历和跨端同步。** 先提供可预览、去重的任务／选课／手动修改导出与恢复，排除会话和带票据链接；可信日期可选导出日历。当前没有这些功能，也没有 Windows 与手机自动同步服务。
