# 登录状态已知问题

2026-11-09 核对 Windows 1.1.1（安装包构建 `20261106-184644-b9a71520`）发现以下问题。以下仅记录票据期限和结果，不包含账号、Cookie 值或令牌。

| 平台 | 已确认的现象 | 当前处理 |
| --- | --- | --- |
| 智慧树 | 本次保存的 `jt-cas` 内部有效期为 24 小时，Cookie 本身没有到期时间；到期后官方单点登录检查也返回未登录 | 在平台连接窗口完成官方登录，等待“登录已确认”后关闭 |
| U 校园 | 本次保存的 `jwt` 内部有效期为 48 小时，Cookie 本身没有到期时间；当前保存的 TGC 无法续期，官网返回登录表单 | 在平台连接窗口重新登录，确认课程目录读取完成 |
| PTA | 后台账号检查报未登录时会删除加密归档；新登录在后台检查完成前关闭窗口可能漏存 | 重新登录后等待“登录已确认”再关闭窗口，过期归档保留及提前关闭保存仍待修复 |

上述 24／48 小时来自本次票据的实际时间字段，不代表所有账号或未来版本都采用相同期限。保存时间也不等于最近一次成功登录时间。

本地加密保存只保证 Cookie 可以恢复，不会延长官网的票据或服务端单点登录期限。程序已实现的官方续期需要现有单点登录仍有效；官方单点登录也过期时，必须本人重新登录。

本次诊断未修改正式任务库、登录仓库或浏览器 profile。以上问题尚未在当前 1.1.1 安装包中修复。
