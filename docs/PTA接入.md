# PTA 教学课程与题目集

2026-11-04 新增 PTA（`pintia.cn`），优先覆盖教学课程中的题目集。左侧 PTA 卡片打开独立平台管理窗口，集中提供登录、课程刷新、选择、同步、自动开关与结果详情，支持缩放和收起课程区。任务进入同一首页清单、来源统计、状态和截止时间筛选。

## 使用

1. 点击旧版本的“退出程序”，再双击 [启动聚合平台.cmd](../启动聚合平台.cmd)。关闭窗口的 × 仅隐藏到托盘。
2. 打开左侧 PTA，点击“连接平台”，在下方官方登录页完成登录与验证码。
3. 刷新课程列表，勾选需要记录的教学课程，点击“保存选择并采集”。未确认范围前只读取课程目录，未选课程不读取个人答卷。
4. 查看首页题目集的状态和截止时间，点击任务名称打开官方题目集概览；实际答题和结束答题由本人在官网完成。

登录确认后，Cookie 用 Windows DPAPI 当前用户加密保存到任务库的 `platform_sessions` 表，每个平台一份当前会话。启动默认复用，后台每 30 分钟更新已选课程；官方明确返回未登录时标记过期并引导再次登录，新登录替换旧 Cookie。网络或课程权限错误保留已有记录。当前 profile 的新 Cookie 优先，HTTP 续期与删除写回，退出前等待同步结束并保存。

## 官方只读契约

接口依据 2026-11-04 PTA 主站与题目集应用的公开前端资源核对，教学班级类型为 `STUDENT_USER`，兼容 `LEGACY`。课程目录同时读取可见班级和教学题目集关联，补充教师隐藏但仍有教学题目集的班级；公共练习和邀请内容不作为教学课程。内部页号从 1 开始，请求转换为官方从 0 开始的页号。

| GET 路径 | 用途与字段 |
| --- | --- |
| `https://passport.pintia.cn/api/u/current` | 登录检查，账号来自 `user.id`；HTTP 200 的游客标记仍表示未登录 |
| `/api/user-groups/member-visible?page=0&limit=12` | 可见教学班级，`userGroups`、`total` |
| `/api/problem-sets?filter={"userGroupMemberJoinType":"CLASS"}&page=0&limit=30&orderBy=END_AT&asc=false` | 教学关联目录，`problemSets`、`total`、`userGroupsByProblemSetId[id].items`；查询值由程序编码 |
| `/api/problem-sets/user-groups/{classId}?page=0&limit=20&orderBy=END_AT` | 已选班级的题目集，`problemSets`、`total` |
| `/api/problem-sets/{setId}/exams` | 已选题目集的个人答卷元数据，`problemSet`、`exam`、根字段 `status` |

目录阶段只扫描班级和教学关联元数据，不读取个人答卷或导入任务。分页必须符合总数、长度和唯一标识；最多每类 100 页、单轮 600 次请求。总数变化、重复、分页不完整和未知结构明确报告，不能当作零课程或零任务。教师隐藏班级入口不可完整读取时，只有完整确认的教学关联集合才能作为替代来源。

个人答卷必须属于当前账号和题目集。保存课程目录和每批任务前复查账号，并检查 Cookie 会话代次及课程选择版本；旧登录或旧选课请求不能导入。只发送 GET 元数据请求，不发送开始考试的 POST，不读取题目、草稿、答案或提交内容。具体入口固定为 `https://pintia.cn/problem-sets/{id}/exam/overview`，由系统浏览器打开，系统浏览器沿用自己的登录状态。

官方登录使用 `TCaptcha.js`。只允许公开脚本确认的 `turing.captcha.qcloud.com` / `ca.turing.captcha.qcloud.com` 验证码内嵌文档：`placeholder_v2.html`、`new_slide_placeholder.html`、`drag_ele.html`、`drag_ele_global.html`。验证码不能替换主登录页面，其 Cookie 不进入 PTA 会话仓库。登录诊断仅保存阶段、分类和计数，不保存 URL、验证码票据或账号凭据。

## 状态和日期

| 官方依据 | 聚合状态 |
| --- | --- |
| 常规题目集无个人答卷，根 `status=PENDING/READY/END` | 未完成；题目集关闭不代表已完成 |
| 个人答卷 `status=PROCESSING`，`ended=false` 或省略默认 false | 未完成，显示答题中；分数或通过题数不代表完成 |
| 个人答卷 `status=END` 且 `ended=true` | 已完成，显示“已结束答题”；成绩以官网为准 |
| `status=END` 但 `ended=false` 或未提供 | 待核对，可能为超时停止 |
| 互评、特殊题目集或未知字段 | 待核对，明确提示流程未完整覆盖 |

带时区的完整 ISO 日期转换为 UTC 保存、北京时间显示。`FIXED_TIME` / `FIXED_DURATION` 中尚未结束的个人答卷采用 `exam.endAt`；教师延期字段 `delayedEndAt` 保留为时间依据。`ended=true` 后 `exam.endAt` 是实际结束时间，继续保留题目集设置的截止时间。`ALWAYS_AVAILABLE` 明确显示无截止时间。缺失时区、反向时间或无法确认的个人截止时间不猜测。原始状态、结束标记与时间字段保存在任务的平台依据中；手动修改优先。个人答卷读取失败不能用低置信度结果覆盖已确认完成状态。

公共练习库、PAT 题库、逐题完成率、互评完整流程及其他特殊考试暂未覆盖。

## 故障与验证

| 提示 | 处理 |
| --- | --- |
| `PTA001` | Cookie 失效，在 PTA 官方登录窗口重新登录 |
| `PTA002` | 网络、登录页或平台请求错误，保留数据后重试 |
| `PTA003` | 结构、身份、状态、时间或特殊流程待核对；打开官网核对 |
| `PTA005` | 分页、请求上限、重复页或限流，本次未完整读取 |
| `PTA006` | 课程权限或入口不可用，核对官网课程；不直接解释为登录过期 |

`PERMISSION_DENIED` 与 HTTP 403 不作为注销；`USER_NOT_LOGGED_IN` 明确标记过期；其他未知错误不当作空列表。任务、课程选择和人工修改保留。
