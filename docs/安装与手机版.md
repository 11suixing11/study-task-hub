## Windows 安装和旧记录

先在旧版首页点击“退出程序”，再双击 EXE，按中文安装向导操作。右上角 × 只隐藏到托盘。安装版已包含 .NET 运行环境，不需要安装开发 SDK 或 Python；首次缺少 WebView2 时向导会安装 Microsoft 官方运行时。EXE 当前没有发布者签名，Windows 可能显示“未知发布者”。

首次安装可以选择“导入这台电脑上的旧版聚合平台记录”，选择包含 `.local/data/tasks.db` 的旧项目文件夹，例如 `C:\Users\yuki\Desktop\聚合平台`。导入只复制 SQLite 记录和旧版加密会话归档，保留源文件；浏览器 profile 不复制。已有安装版任务库时，升级继续使用已有记录，不覆盖成旧库。

从桌面或开始菜单“聚合平台”启动。安装程序与任务数据分开保存：

| 内容 | 默认位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\LearningTaskAggregator` |
| 任务、选课与加密 Cookie | `%LOCALAPPDATA%\LearningTaskAggregator\.local` |
| 原项目记录 | 原项目的 `.local`，导入后仍保留 |

升级前退出程序，重新运行新安装包。Windows 卸载只移除程序，保留外部数据；同一 Windows 用户重新安装后继续使用。Cookie 和任务入口使用当前 Windows 用户加密，不能直接拷贝到其他用户或手机使用。若官网已过期，在相应平台重新登录即可，已有任务保留。

## Windows 便携版

将 ZIP 完整解压到可写文件夹，打开“聚合平台-1.1.1-便携版-win-x64”目录，再双击“启动聚合平台.cmd”。其中 `app` 目录包含正式程序、.NET 运行环境与第三方许可，不要单独移动 EXE。

便携版省略安装流程，默认数据仍保存到 `%LOCALAPPDATA%\LearningTaskAggregator\.local`，与同一 Windows 用户的安装版共用。旧项目记录需通过安装向导选择导入；便携入口不会自动搬运旧项目。安装版或便携版切换前均需点击“退出程序”。缺少 Microsoft WebView2 时可运行安装程序，由向导安装官方运行时。

## Android 安装和使用

将 APK 传到手机，在文件管理器中打开，按手机提示允许该来源安装应用。安装完成后打开“聚合平台”；若需要截止提醒，允许通知权限。APK 包含 arm64-v8a、armeabi-v7a 和 x86_64 三种架构及自己的运行环境。

1. 首页找到课程所在的平台，点击“管理平台”，再点击“连接平台”。扫码、密码和验证码由本人在官方页面完成。
2. 登录确认后自动加密保存 Cookie 并读取课程目录；也可点击“登录完成并读取课程”确认。学堂在线需点击官网首页右上角“登录”；MOOC 完成登录后进入官网首页确认账号。
3. 勾选课程，点击“保存选择并采集”。确认选择前只读取目录，新增课程需再次勾选。平台管理可收起和展开课程区域。
4. 返回首页查看统一任务清单，打开任务查看状态、截止与来源。官方入口通过手机浏览器打开，浏览器有自己的登录状态，可能要求再次登录或核验。
5. 可添加手动任务，选择来源平台、课程和截止日期，并在详情调整任务状态。后续采集保留人工修改。

手机任务、选课与加密 Cookie 位于应用的私有目录。Cookie 和受保护入口使用 Android Keystore 加密，重启默认复用；官网明确失效时标记过期、引导重新登录并替换当前会话。原生 WebView 的登录环境留在手机应用内。

Windows 与 Android 独立保存数据和登录，不提供跨设备任务合并或 Cookie 传输。更新 APK 时使用同一签名覆盖安装，可保留应用数据；Android **卸载应用或清除应用数据会删除手机记录和密钥**。Windows 卸载的数据保留行为不适用于 Android。

应用在前台时每 30 分钟自动同步已连接平台的已选课程，也可手动同步。后台只按系统调度检查已有提醒，不保证后台采集；省电策略、通知权限和系统调度可能使提醒延迟。

## 覆盖与验证

Windows 安装、旧库与可解密合成 Cookie 归档导入、覆盖升级、卸载保留数据均通过隔离验证。完整回归 2,996 项业务、1,162 项桌面与重启、40 项 Python 检查，11 个项目零警告、零错误，其中首页 77 项。便携包 607 个文件全部解压校验与启动通过，十档嵌入图标一致。见 [发布报告](../artifacts/releases/20261106-184644-b9a71520/verification/verification.json)、[安装](../artifacts/installers/20261106-184644-b9a71520/verification/installation-checks.json)、[便携启动](../artifacts/installers/20261106-184644-b9a71520/verification/portable-startup-checks.json)与 [图标](../artifacts/installers/20261106-184644-b9a71520/verification/icon-package-checks.json)。另以隔离会话副本真实只读验证 U 校园账号和 30 个单元采集，正式数据库与 profile 未改写，见 [结果](../artifacts/installers/20261106-184644-b9a71520/verification/ucampus-product-readonly-checks.json)。智慧树真实账号续期与最终官方任务页仍待验收；1.1.0 品牌设计的 26 项 WPF 检查保留为历史证据。

Android APK 已通过签名校验，并在 Android 15 专用模拟器上通过 34 项原生合成检查、4 项跨进程恢复和 4 项覆盖更新恢复。验证包括原生 SQLite、Keystore Cookie 加密、选课后定向同步、人工修改优先、失效保留任务、系统边距及提醒组件冷启动。首页、平台页中文及课程区展开收起已检查；界面录入的手动任务、备注和完成状态在进程重启后保留。见 [Android 构建清单](../artifacts/android/package.json)、[原生安装验证](../artifacts/android/verification/20261105-091725/installation-checks.json)和 [页面操作检查](../artifacts/android/verification/20261105-091725/ui-review/ui-checks.json)。实际手机上的各官网登录、验证码、课程完整性和最终任务页面仍待验收，不能用合成测试证明真实账号同步成功。

平台只采集课程、任务和完成状态等元数据，不读取题目或答案正文，不开始或提交考试。未知结构、不完整分页与未知状态会保留错误或待核对，不能解释成没有任务。PTA 优先教学课程中的题目集；智慧树资源学习、部分 AI 智课任务、互评及特殊考试仍可能未覆盖，详细范围见 [PTA](PTA接入.md)、[智慧树](智慧树接入.md)、[U 校园](U校园接入.md)及其他平台说明。

## 重新构建

在项目根目录执行：

```powershell
# 完整桌面构建与发布，再生成对应 Windows 安装包
.\scripts\build.ps1
.\scripts\build-installer.ps1

# 使用已安装的 Android SDK、.NET Android workload 与 JDK 21 构建签名 APK
.\scripts\build-android.ps1
```

Android 发布密钥及 DPAPI 保护的密码位于本机 `.local/android-signing`，仅构建使用，不随安装包分发。发布更新必须复用同一密钥并增加 VersionCode。手机合成测试入口为 `tests/MobileChecks`，使用独立测试根目录；模拟器原生验证须指定专用测试设备，不能在本人正式手机数据上运行。

`scripts/test-android-installation.ps1` 用于已经建立合成数据基线的专用模拟器，检查同一 APK 的覆盖安装和跨进程恢复；验证通过后按 APK SHA256 更新构建清单，页面目视检查单独记录。首次设备需先运行移动合成检查建立基线，不能把缺少基线解释为升级成功。
