# 学堂在线接入

Windows 版本已接入学堂在线新版主站普通课程的练习与考试：官方登录、课程目录、按课程选择、任务状态和截止日期、具体官方入口及加密会话恢复均已接入首页。实现经官网公开脚本和本地合成响应核对，真实账号课程完整性与最终页面仍待验收。

## 使用与范围

2026-11-03 起，从左侧打开学堂在线平台管理，点击“连接平台”，进入 `https://www.xuetangx.com/`，点击官网右上角“登录”，在官方弹窗完成登录。电脑端直接访问 `/login` 会挂载默认隐藏的登录弹窗，不能作为显示表单的入口。后台确认后保存最新 Cookie，并先读取正在上课、即将开课、已结课与已收起课程；用户勾选并点击“保存选择并采集”后，只同步已选普通课程的练习和考试。已连接且开启自动同步时，在启动及每 30 分钟更新已选课程。

平台管理集中提供连接、刷新、选择、同步、停止与自动开关，支持缩放及收起课程区，没有多用户选项。新安装和旧配置迁移均需确认选择，新增课程需要再次勾选。“刷新课程列表”只更新目录，任务同步结果独立保留；取消选择后的任务仍存于本地，重新勾选可恢复。账号、课程与课堂共同隔离任务。

| 内容 | 当前覆盖 |
| --- | --- |
| 新版主站普通课程 | 课程目录、章节练习和考试 |
| 任务学习进度 | 官方个人 `leaf_schedules` 元数据 |
| 任务日期 | 开放时间、评分截止、结束时间与已确认的延期记录 |
| 任务入口 | 官网具体练习或考试路由，打开前校验任务归属 |
| 旧版课程、多课项目 | 尚未覆盖，报告限制并保留已有任务 |
| 讨论、视频及其他学习活动 | 不纳入当前任务采集范围 |

每个课程目录分类最多 100 页，单轮最多 1,200 次元数据请求。分页总数变化、重复页、异常提前空页、未知结构、限流与上限不能当作无任务；同步详情保留具体原因。

## 状态与日期

状态取自官方课程页学习进度：100% 显示“已完成（平台学习进度）”，低于 100% 显示待办并保留百分比；缺少可识别进度时显示待核对。学习进度不能代替提交、批阅或考试有效性证明，请在官方任务页核对。手动状态和字段不被后续同步覆盖。

截止日期先使用归属已确认的任务延期记录；没有该任务延期记录时，使用评分截止与结束时间中较早的明确时间，并保留两者原始依据。延期接口或归属未确认时，截止日期显示待核对，任务与入口保留；课程结束日期不作为任务日期。日期异常或起止矛盾也不会猜测。

点击任务名称或“打开官方任务”使用系统浏览器打开具体 `/learn/.../exercise/...` 或 `/learn/.../quiz/...` 地址，打开前读取最新链接并校验课程、课堂和任务。系统浏览器沿用自身登录状态，可能需要登录或继续跳转；最终页面仍待真实账号验收。后台不读取题目、答卷或执行提交。

## 会话与故障

学堂在线使用独立 WebView2 登录目录，最新 Cookie 用 DPAPI 当前用户加密保存到任务库 `platform_sessions` 表；旧 `.local/sessions/xuetang.bin` 兼容迁移。启动和连接默认复用有效 Cookie，保留官方有效期，不额外设置 30 天期限；HTTP 续期或删除写回原环境和仓库。明确过期时保存失效标记并引导官方重登，成功后更新 Cookie，旧响应不能覆盖新会话。支持登录成功但页面未跳转、退出等待和完整进程重启恢复。

2026-11-03 重新核对官网 1.6.376 公开资源，确认电脑端 `/login` 路由默认隐藏登录表单，官网首页的“登录”按钮才会开启弹窗。因此连接窗口改为官网首页，并说明点击位置；保留 `/login` 与其他官方回跳地址。

首次打开与点击“打开官方登录”时仅刷新 WebView 页面磁盘缓存，保留 Cookie 和登录存储。官方应用脚本或样式返回错误或 HTML 替代内容时，显示 `XT002` 并引导刷新；成功加载的空页面也不能报告为“已就绪”。后台登录检查不会覆盖页面错误，明确刷新会开启新一轮诊断。诊断仅保存阶段、分类、状态码与计数，写入 `.local/diagnostics/xuetang-login.json`，同步详情可查看最近原因，不保存凭据、页面正文或原始 URL。

已按当前公开脚本适配 hCaptcha 和腾讯验证码的明确内嵌文档路径；这些路径只允许嵌入官方主页面，不能替换主页面或扩大任务接口范围。验证码仍由用户在官网完成。弹窗导航继续延后到事件结束，保留此前本地 HTTP 回跳回归。见 [平台入口核查](平台入口核查.md)。

| 错误码 | 处理 |
| --- | --- |
| XT001 | 在“连接学堂在线”完成官方登录；任务保留 |
| XT002 | 网络、读取或数量校验未完成，查看同步详情后重试 |
| XT003 | 元数据、账号归属、部分任务或多课项目尚未确认，核对官网 |
| XT004 | 会话保存或清理失败，检查本地目录权限 |
| XT005 | 限流、重复分页或读取上限，当前覆盖未确认 |
| XT006 | 延期记录的结构或归属未确认，先在官网核对截止时间 |

## 验证

学堂在线业务检查覆盖官方请求范围、四类目录、分页异常、延期、学习进度、任务隔离、手动保留与取消。`XuetangSyncHarness` 使用独立合成库、本地 HTTP 与 WebView 响应验证目录先行、选择后定向采集、统一清单、入口、Cookie 保存、会话失效和跨进程恢复。新增登录页面检查覆盖 200 HTML 替代脚本、样式失败、空壳、错误提示保留、刷新后脚本执行、Cookie/localStorage 保留、官网首页表单入口、验证码内嵌页和无关导航拦截。当前发布及检查计数见 [开发进度](开发进度.md) 和对应 `verification.json`。

本轮未登录真实学堂在线账号或将合成任务写入正式库。真实验收仍需确认本人普通课程的练习和考试，核对学习进度与提交状态的差别、延期后的截止日期及系统浏览器最终页面。
