# Android Root 会话复用验证

2026-11-11 在用户本人连接的 PLQ110、Android 16（API 36）手机上验证，`su` 返回 `uid=0`。这是已登录官方 App 的历史独立诊断。用户随后要求延期 Root 提取、优先修复手机登录跳转，Android 1.1.2 VersionCode 4 未增加 Root 导入功能；本报告不作为新版 APK 的真实账号验收。

| 平台 | 手机 App 版本 | 本次结果 |
| --- | --- | --- |
| 学习通 | 7.0.6 | 官方 App 的 WebView Cookie 可读。现有聚合平台 HTTP 读取器复用会话，门户和课程目录均返回 HTTP 200，解析出 19 门课程，未跳转登录。 |
| U 校园学生版 | 3.0.2.6 | Root 可读私有目录；WebView 仅有词典、论坛的 2 条 Cookie，没有找到课程或 SSO Cookie。检查的 6 份原生配置都是加密容器，尚未验证解密及会话复用。 |
| 知到／智慧树 | 未检测到安装 | 没有该 App 的会话可供验证。 |

学习通验证直接复用了现有读取器和解析器，Cookie 通过进程标准输入在内存中传递，没有输出或保存会话值。未把会话导入正式应用，没有修改官方 App 数据或正式任务库。只读取门户及课程目录，未读取任务正文、题目或答案，也未提交任何学习操作。

学习通结果证明本次会话可以用于课程目录读取；尚未验证手机内 Root 导入、完整任务采集、长期续期、撤销处理，以及门户账号与 App 账号的独立比对。因此不能据此宣称所有平台都可永久免登录。

U 校园原生账号库的表结构已检查，没有从这些检查中确认可用登录令牌。原生配置另有加密，读取权限不保证会话可解密。手机断开连接时运行验证尚未完成；用户已要求延期，本轮不继续调查。

断联后电脑另检测到一台 fastboot 设备，其型号与此前 PLQ110 不一致；未对其执行重启、刷写或解锁。
