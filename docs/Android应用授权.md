# Android 应用授权接入

2026-11-11 更新。Android 1.1.2 登录跳转修复版（VersionCode 4）提供**官网二维码辅助免密码登录**：保存当前官网二维码，打开手机上已登录的官方 App，由本人从相册扫码并确认，返回聚合平台检查官网登录结果，再读取课程。该方式无需第三方开发者注册；原生一键授权及课程任务权限契约仍未接入。Root 提取功能按用户要求延期。

## 1.1.2 使用步骤

1. 在聚合平台打开“管理平台”→“连接平台”，点击“官网扫码登录”，等待官网二维码显示。学堂在线先点击官网右上角“登录”。
2. 点击“保存并打开学习通／U 校园学生版／知到／微信”，或先“保存登录二维码”再自行打开对应 App。
3. 在官方 App 的“扫一扫”中选择相册，找到刚保存的二维码，按官方页面确认登录。
4. 返回聚合平台，原连接页面继续检查官网会话；也可点击“登录完成并读取课程”。请等待“登录已保存”或课程目录加载完成，再离开连接页并选择课程采集。

此前学习通出现“该登录跳转尚未适配”时，覆盖安装新版后重新打开官方登录、保存新的二维码并扫码。新版将已确认的学习通旧 HTTP 返回地址和新窗口地址等价升级为 HTTPS，保留路径、参数和片段，限制反复降级；补齐课程域名和路径作用域的 Cookie 读取。16 项隔离检查已验证该路径和课程会话交接，真实手机扫码后的课程读取仍待复验。

二维码会过期，官网更新图片后需重新保存。官方 App 是否允许从相册识别登录二维码取决于其版本；**真实官方 App 相册识别及真实账号扫码到选课采集尚未真机验收**。不支持相册时可用另一台设备扫码，或选择官网提供的短信验证码登录。图片跨域、隐藏或尚未加载时会提示未取得二维码。

## 二维码与手机权限

二维码保存到相册 `Pictures/聚合平台登录`，添加白边并放大到至少 640 像素。只复制官网当前已经显示的图片或 Canvas，不另发生成二维码的请求；保存前后核对当前页面和像素，避免保存刷新前的二维码。

Android 10 及以上通过 MediaStore 保存本应用创建的图片，无需读取相册权限。Android 9 在保存时申请存储写入权限；拒绝后仍可使用官网其他登录方式。离开连接页会尝试清理本应用保存的登录二维码，强制关闭后的遗留图片在下次启动重试清理。扫码确认前请保留连接页。

## 当前登录方式

聚合平台使用自己的 Android WebView 完成官网登录，再通过 Android Keystore 加密保存该登录环境的 Cookie。普通 Android 权限不能读取学习通、知到或 U 校园等其他 App 的 Cookie、私有文件和登录令牌。通知权限用于任务提醒，也不会提供平台账号授权。

实现直接授权，需要平台允许第三方应用调用授权入口，明确调用参数、应用身份、回调结果，以及课程和任务数据的授权范围。仅找到 App 的唤起地址，或获取用于身份识别的授权码，不能证明已有读取任务的权限。

## 原生直接授权的后续接入条件

以下为后续原生授权的技术条件；1.1.2 的官网扫码辅助不依赖这些资料。

1. 平台官方提供的授权 SDK 或授权入口文档，包括必要的应用注册要求。
2. 聚合平台对应的应用标识、包名和签名登记要求，以及回调地址或返回参数约定。
3. 已授权的课程、作业、考试元数据接口和访问范围；当前网页 Cookie 读取器不能直接使用未经确认的 OAuth 令牌。
4. 本人真机验证：已有 App 登录、首次授权、拒绝授权、未安装 App、授权到期与撤销，以及返回聚合平台后的选课采集。

移动客户端应使用平台支持的公共客户端授权方式；若交换授权码必须使用保密凭据，应由受控服务处理。不要把开发者密钥放进 APK，文档核对也无需提交密码或密钥。

## Root 会话复用延期

2026-11-11 的历史只读诊断在用户本人 Root 手机上，通过学习通 7.0.6 的 WebView 会话读出 19 门课程；U 校园配置未确认可用会话，手机未检测到知到。结果见 [Root 会话验证](AndroidRoot会话验证.md)。用户随后要求延期 Root 提取、优先修复手机登录跳转，1.1.2 不含 Root 导入。这份历史诊断不作为新版 APK 的真实账号验收。
