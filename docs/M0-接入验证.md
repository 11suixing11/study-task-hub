# M0：学习通接入验证

> 本文是早期接入探针说明。当前启动入口为[启动聚合平台.cmd](../启动聚合平台.cmd)，首页点击“学习通采集”；登录后可读取并保存作业列表。当前使用步骤见[读取作业页](读取作业页.md)，功能进度见[开发进度](开发进度.md)。无需为了结束验收而清除现有登录会话。

## 当前交付边界

这是官方登录环境、单页通知只读探针与脱敏人工验证工具，不是完整桌面产品，也不是已完成的作业采集器。它不自动请求课程接口、不猜测任务分页、不将页面打开等同于登录成功。

使用独立 WebView2 配置，不读取现有 Edge／Chrome 配置。只允许 HTTPS 超星／学习通域名作为页面导航；外部统一认证、部分第三方登录可能被阻止，须先评估所需域名。官方页面仍会加载其自身资源和执行自身行为，工具不保证第三方页面的所有请求都是 GET。

## 运行

在项目目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Launch
```

该参数只作用于此 PowerShell 进程，不修改系统执行策略。脚本使用项目内 SDK，还原依赖、编译、执行策略检查后启动窗口。首次还原依赖需要网络。关闭验证窗口后命令结束。

## 人工核对步骤

1. 点击“打开官方登录”，确认站点属于官方域名，仅使用本人或明确授权的账号。
2. 自行在官方页面完成验证；不要把密码、Cookie 或验证码发给助手。
3. 手动浏览课程与作业列表，分别勾选确实观察到的能力。不点击提交、答题或交卷进行测试。
4. 如需网络状态计数，主动勾选记录选项；它只统计 HTTP 响应状态类别，不记录具体请求地址、请求头、正文或响应内容，也不是通用抓包功能。
5. 导出脱敏验证记录。生成的 JSON 只证明人工观察，自动采集相关字段始终标记未实现。
6. 结束后清除登录数据。清理完成后四个操作按钮恢复，可直接点击“打开官方登录”核对是否回到未登录状态，无需重启。

二维码过期或扫码未完成时，点击“刷新登录页”重新加载当前官方页面；空白页则打开官方入口。刷新不清除登录数据，也不保证解决平台侧扫码故障。清理失败会明确提示不能确认退出，并恢复操作入口供重试。

## 单页通知读取试验

报告 v3 将独立 HTTP 接口响应拆分为 401、403 和 3xx，`noticeProbe.http` 记录状态码与脱敏重定向类别，不记录完整目标地址。遇到 3xx 不自动跟随，遇到 403 不直接断定账号被封或登录失效。若需排查，请在新版窗口点击一次“读取通知（试验）”，再导出记录；无需清理已有登录数据。导出前不要再导航，以免本次结果按隔离规则被清除。

完成官方登录后，点击“读取通知（试验）”并确认本次授权。工具从独立 WebView 配置中获取适用于固定通知接口的会话 Cookie，仅在内存中交给临时 HTTP 客户端；发送一次 POST 表单请求，不跟随重定向、不重试、不提交任务。只读取第一页，`lastValue` 留空，不自动翻页。两次操作至少间隔 60 秒。

如需区分独立 HTTP 客户端与内嵌浏览器的请求上下文，可在官方 HTTPS 页面点击“浏览器内验证通知接口”。该操作由当前页面上下文以 `no-cors` 模式发送同一固定接口的 POST 表单请求，使用 WebView 自身的凭据和跨域规则，禁止跟随重定向，不读取响应正文；页面只能得到 opaque／opaque-redirect 结果，不能从页面读取 HTTP 状态。探针只为固定 URL、Fetch 上下文临时启用 WebView 请求钩子，覆盖 Document、Service Worker 和 Shared Worker 来源，并记录请求钩子是否触发、响应事件是否出现、Fetch 状态/响应类型及窗口内观察到的状态码；不会记录具体地址、请求头、Cookie 或正文。请求钩子只说明请求进入 WebView 请求派发流程，不证明服务端收到；WebView2 也不保证响应事件与页面 Fetch 一一对应，因此响应状态只作窗口内观察。该试验可能发送页面 Origin/Referer 等浏览器请求元数据。两种探针共用 60 秒冷却。

报告 v4 的 `noticeProbe.browserContext` 增加 `RequestObserved` 与 `ResponseObserved`，用于区分请求钩子、响应事件和页面 Fetch 三种观察。`false` 表示验证窗口内未观察到对应事件，不等同于平台确认未收到请求。

- 固定接口：`https://notice.chaoxing.com/pc/notice/getNoticeList`，方法为 `POST`，表单字段参考公开实现；不代表官方开放 API 合约，尚未经用户真实账号验证。
- 表单包含 `type`、`notice_type`、`lastValue`、`sort`、`folderUUID`、`kw`、`startTime`、`endTime`、`gKw`、`gName`、`year`、`tag`、`fidsCode`、`filterSenderPuids`、`filterTags`；首请求的 `lastValue` 为空。当前工具只请求一页。
- 超星与学习通域名的会话不保证通用；即使网页登录成功，通知接口也可能仍需认证。本工具不会把另一域名 Cookie 伪造为目标域名 Cookie。
- 响应上限 2 MiB；页面导航、清理登录数据或关闭窗口会取消正在执行的读取并丢弃结果。
- 返回网页、重定向、限流、HTTP 错误、结构变化分别提示，不当作“没有作业”。
- 若接口 JSON 明确返回失败标记，也单独归类为接口拒绝，不当作“没有作业”。
- 有效结果仅在内存展示标题、课程和通知中的截止时间，不导出这些字段；时间单位采用公开参考中的毫秒，不猜测秒单位。2000—2200 年以外的时间按异常处理，不当作真实截止日期。
- 缺失或为零的时间显示未知／未提供，不擅自认定为无截止日期；平台提交状态始终未知。
- 不读取通知附件链接，不使用原始通知中的链接自动打开页面。
- 同名或重复通知不自动合并，不宣称条目数量等于作业数量；未验证通知键的跨课程唯一性。
- 只读取接口默认的一页，不猜测分页参数；空页不代表没有作业，解析成功也不代表账号身份、任务覆盖或提交状态已验证。
- 脱敏报告增加读取结果类别与作业通知数量，完整采集字段仍标为未实现。

测试不需要发送密码、Cookie 或课程原始数据。可以反馈界面的错误类别、是否显示通知以及与原平台人工核对是否一致。遇到登录失效请用官方页面处理，不反复点击尝试。

## 文件位置

- `.tools/dotnet`：项目内 SDK；下载包按官方发布元数据的 SHA-512 校验。
- `.tools/nuget`：依赖与 NuGet 缓存。
- `.local/temp`：开发和运行临时目录。
- `.local/webview-profile`：独立登录配置，含敏感会话与缓存，不应上传或分享。
- `artifacts/probe-reports`：用户主动生成的脱敏报告。
- `src/AccessProbe/bin`、`obj`：构建产物。

清除浏览数据不等同于删除整个配置目录。需要彻底移除本项目的登录容器时，关闭本工具并确认其 WebView 子进程已结束，然后仅删除 `.local/webview-profile`。不要删除自己的普通浏览器配置。不要把整个项目打包分享，除非先排除 `.local`、`.tools`、`artifacts` 和构建目录。

## 尚未验证

- 官方登录在真实账号下的可用性及学校统一认证差异。
- 官方登录返回的账号身份与课程所属账号一致。
- 课程列表、作业分页、完整性和稳定任务 ID。
- 截止时间的单位、时区与无截止日期语义。
- 平台提交状态的字段含义和更新延迟。
- 会话过期识别、重新登录和隔离清理效果。

后续根据真实页面的授权观察确定只读接口契约，再实现适配器。不会复制 AGPL 项目实现或把通知列表未经验证地当成完整作业列表。
