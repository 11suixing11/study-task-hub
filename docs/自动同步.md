# 登录账号后自动采集

已接入学习通、雨课堂、长江雨课堂、中国大学 MOOC、学堂在线、智慧树、旧版 U 校园与 PTA，FiF 停用。2026-11-03 改为登录确认后保存最新 Cookie、先返回全部课程目录、由用户确认选择后定向读取任务；2026-11-04 PTA 同样接入该流程。首次使用与旧配置迁移均不会默认抓取全部课程，新课程需要再次勾选。已连接且开启自动同步的平台在启动时及每 30 分钟同步已选课程。首页统一显示各平台的可见任务与手动任务；“查看全部任务”清除搜索和筛选，仍遵循已保存的课程范围。本文说明学习通链路，其余平台见对应接入文档。

左侧平台管理窗口集中提供“连接平台”“刷新课程列表”“同步已选课程”“保存选择并采集”、停止和自动同步开关，支持缩放及收起课程区。界面沿用 macOS 风格布局、WPF UI 主体和 Fluent 图标，仅维护当前使用者，没有多用户或账号切换选项。课程选择确认前历史任务继续可见，确认后默认隐藏未选课程的历史任务并停止相关采集与提醒；数据仍保留。

智慧树目录包括翻转课、共享课、进行中和已完成智慧课程及 AI 智课／智能体课。新版智慧课程选课后读取作业、考试的未完成与已完成列表并核对总数，其他学习任务与旧版入口明确提示未覆盖。当前登录、最近课程刷新和上次任务同步分开展示，目录错误不要求重复登录。详见 [智慧树接入](智慧树接入.md)。

PTA 先返回可见教学班级及教学题目集关联的课程，用户确认后只读取已选课程的题目集与个人答卷元数据。明确结束答题才标为已完成，超时停止标为待核对，一直可用的题目集显示无截止时间。只读 GET 不开始考试，入口打开官方题目集概览。详见 [PTA 接入](PTA接入.md)。

U 校园选课后独立读取作业、测试和普通课件单元；按终点必学标记与实际完成进度，计算未完成必学项的最早截止并排列首页优先级。单元覆盖失败保留历史，不阻断已确认的作业/测试列表。同步详情分别列出单元、限时单元、必学未完成数量及单元覆盖情况，不生成每日学习计划。详见 [U 校园接入](U校园接入.md)。

登录窗口和后台会话共用同一 WebView2 environment 和项目 profile。后台只发送适用于目标官方地址的 Cookie，不读取普通浏览器或保存账号密码。登录页面有导航时触发检查；没有主页面导航时，连接窗口打开期间每 5 秒检查登录会话。上一轮同步尚未结束时，登录后的检查会排队执行。清除登录数据时停止同步，重新登录后自动恢复。

八个平台的 Cookie 快照用 Windows DPAPI CurrentUser 加密写入 `.local/data/tasks.db` 的 `platform_sessions` 表，每个平台只保留当前会话；旧 `.local/sessions/*.bin` 兼容迁移。启动时在首次请求前恢复缺失且未过期的 Cookie，保持 domain/path、Secure、HttpOnly、SameSite、平台有效期与 session 属性；当前 profile 的同名同域同路径 Cookie 值发生变化时，旧快照不参与恢复。按 Cookie 实际有效期判断，不设置额外 30 天截止；损坏或未知格式不恢复。登录确认、同步续期、关闭连接窗口及退出前保存最新状态，退出先取消并等待后台同步，再保存与释放 WebView。

HTTP 读取从当前 profile 构造每次请求的 Cookie。官方响应的 `Set-Cookie` 续期与删除写回共享 CookieManager；已确认的有效续期保存到加密仓库，拒绝响应删掉部分 Cookie 后不能用残缺快照覆盖最后有效凭据。读前及响应后检查会话代次和内存指纹；新登录、认证 Cookie 变化、清除或退出期间返回的旧响应不写回，也不记录为新会话失败。智慧树 `acw_tc` 和 U 校园已确认辅助 Cookie 不参与认证变化判定，指纹不进入报告。

U 校园与智慧树遇到课程未登录响应先复核账号，同账号确认后重试一次。短期会话失效可沿已确认、有限跳数的官方 SSO 链路续期并回存，再确认同一账号；智慧树过期学生 token 可回退 CAS Cookie 复核。网络、权限和未知结构分别保留，不作为注销。两平台明确失效保存过期标记和受保护的复核凭据，默认恢复不激活，只有官方复核成功才恢复已登录；其他平台仍沿用原失效清理策略。用户“清除登录数据”等待旧请求结束并永久移除该平台仓库和 profile，保留任务。

连接窗口关闭时立即保存新认证 Cookie，即使五秒检查尚未运行；有账号证据但未完成接口复核时保持已保存待确认，不冒充已登录。退出前取消、等待请求后保存，已失效凭据不会被旧退出保存重新激活。两平台续期和重试都计入实际请求上限。

旧版已经丢失的临时 Cookie 不能重建，首次切换仍提示 `SYNC001` 时需完成一次官方登录。此修复的跨进程重启合成验证已通过，真实账号使用新发布完整退出后的验收仍待用户切换。平台注销、撤销和到期仍需官方登录。

## 请求链路

1. GET `https://i.chaoxing.com/base`，从页面读取唯一 fid；缺失或互相冲突时停止，不猜学校或账号参数。
2. GET `https://mooc2-ans.chaoxing.com/mooc2-ans/visit/courselistdata`，读完已适配分页并保存课程入口和课程名，包括没有作业的课程。选择未确认时在此停止，不请求课程任务。
3. 用户确认课程选择后，只 GET 已选课程的 `/visit/stucoursemiddle` 入口；已适配平台 302 到 `mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu` 的跳转。课程、班级与 cpi 必须保持一致，直接使用平台返回的地址读取 workEnc、enc、openc、examEnc 和 t。
4. GET `/mooc2/work/list`，使用 workEnc 作为作业列表签名，逐条读取名称、平台状态、时间原文和具体任务地址。
5. 对每门已选课程再 GET 一次课程级考试列表 `/exam-ans/mooc2/exam/exam-list`，参数为课程页 hidden 的 courseid、clazzid、cpi、ut、t、stuenc（=enc）、enc（=examEnc）、openc；考试签名与作业的 workEnc 相互独立。逐行读取考试名称与平台状态，并从行内 `onclick="viewExamAnswer('examId','relationId')"` 的字面参数取考试身份；不执行页面脚本。考试列表本身没有时间列，因此考试不带推断的截止日期。
6. 按课程/班级/cpi/work ID 去重保存；使用页面给出的 `/mooc-ans/mooc2/work/task` 详情地址读取作答时间原文，自动同步平台明确状态并保留手动状态和编辑。已适配到 `/work/view` 与 `/work/prompt` 的跳转，继续请求前校验同一课程、班级、cpi、work ID 与已知 answer ID；原任务链接保持列表返回的签名地址。考试按课程/班级/exam ID 去重保存，入口保留考试列表地址。
7. 平台转入 `/work/dowork` 作答流程时，在请求该页面前停止，记录“详情转入作答页面”，列表任务仍保留。提交提示页只提供“提交时间”时，记录“平台未提供作答时间”，不把提交时间当作截止日期。考试一次只读列表，不进入考试页、预览或作答流程。

请求链路参考公开项目的 Web 请求契约并独立实现：[Xuexitong-mcp client.py](https://github.com/DanMo661/Xuexitong-mcp/blob/main/xuexitong_mcp/client.py)。公开实现不能替代本人账号对页面、完整性和签名的验证；不使用参考项目的登录自动化、参数兜底或作业/考试操作。

## 完整性与限制

已识别的课程和作业分页链接自动跟随。未知分页、页面结构、课程权限、登录失效和读取上限会显示错误码，不作为空课程或空作业处理。单轮最多 200 门课程、每列表 20 页、100 条详情、600 次请求；列表每次更新，详情 24 小时内缓存。

完成、提交、待批阅和已批阅等明确标签归入完成；未交、待提交、进行中等归入待办，被打回和需重做归入被打回。未知或互相冲突的状态不猜测。用户手动操作后状态覆盖位保留，包括恢复未完成；旧版已有的非默认状态在迁移时保留。

作答区间按北京时间（UTC+8）转换；完整年份属于平台完整日期，缺少年份选择与采集时间相近的合理年份并标注“年份推定”。列表仅提供“剩余…小时…分钟”等时，用该列表响应的读取时间换算并标注“约”。推定和估算均参与优先级、逾期和临期筛选，定时提醒须手动核对确认。旧任务启动时迁移，不需要重新导入；缓存作答区间不在重复同步时滚动年份，详情保存也不会把旧倒计时从当前时刻重新计时。平台没有提供可用时间时保留未知。

明确的空作业页支持 `.task-list .has-content > .null-data` 中的“暂无作业”；存在作业行时不按空页处理。明确的空考试页支持 `.main.task-list .has-content` 内为空列表或“暂无考试”；存在考试行时不按空页处理。考试不按状态过滤：已完成的考试照常导入并保留平台状态，已结束或已过期但未作答的考试标为“待核对”，不会静默当作完成；名称、入口或课程归属无法确认的行记入 `ExamsUnresolved` 并报 `SYNC006`，不当作没有考试。当前考试列表不提供时间列，考试任务保持“时间未知”，不从作答按钮或试卷页推断截止日期；作业的时间原文仍按“起止区间”或“剩余…”两类处理。详情的提交提示与作答流程分别计入 `DetailsUnavailable`、`DetailsRequireAction`，可在“同步详情”查看本轮数量。其他未知结构继续报 `SYNC006`。

诊断只保存数量、结果、错误码和读取边界；任务链接由 Windows DPAPI 当前用户保护。`scripts/read-sync-status.py` schema 9 输出八个启用平台的连接、覆盖、任务状态和日期计数，课程目录共九个平台（含停用的 FiF），区分未确认课程选择、已选与未选任务；FiF 只保留手动与历史任务。

## 点击任务直达

首页任务名称为可点击入口，选中任务也可点击“做题 / 提交”；完成任务按钮显示“查看作业”。依据 PRD，页面在系统浏览器打开。点击时重新读取正式库中的最新签名链接，使用项目采集会话对 `/work/task` 发出 GET，仅检查响应头。平台返回同一任务的 `/work/dowork`、`/work/prompt` 或 `/work/view` 后，将原地址交给系统浏览器；不在聚合平台内请求这些目标页面或读取作答正文。HTTP 官方跳转先改用 HTTPS，保留原路径和参数。未知跳转或课程/班级/cpi/work/已知 answer ID 不一致时停止并提示 `LINK003`。

同一任务入口的签名刷新允许最多 6 次响应头请求，并检测重复跳转。平台未跳转时直接打开该任务入口。采集会话失效、网络失败或限流时仍可打开已保存任务入口，由系统浏览器的官方页面处理登录；不会把 Cookie 复制到浏览器。手动录入或用户更换的链接直接打开。打开过程中链接被同步或用户修改时重新读取，任务被删除时停止；点击不修改完成状态、截止时间或提交作业。
