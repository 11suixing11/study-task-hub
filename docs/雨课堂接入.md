# 雨课堂与长江雨课堂接入

2026-10-23 已实现 Windows 版登录后自动采集、状态与截止时间保存、具体任务跳转。当前发布 `20261023-151730-99180b71` 通过 282 项雨课堂业务检查和 88 项独立桌面检查。首页默认将学习通、雨课堂、长江雨课堂及手动任务显示在同一张清单，统一排序、统计与同步。两个平台已用本人账号登录并成功采集；新版正式窗口显示及最终官方作业页仍待重启后核对。

## 使用

1. 旧版仍在运行时，在首页点击“退出程序”；关闭窗口只会隐藏到托盘。
2. 双击项目中的“启动聚合平台.cmd”，点击“连接雨课堂”或“连接长江雨课堂”。
3. 在官方页面完成登录。雨课堂提供 `www.yuketang.cn` 和 `pro.yuketang.cn` 两个站点；长江雨课堂为 `changjiang.yuketang.cn`。选择本人课程所在的站点。
4. 登录后自动发现课程并保存任务。首页默认一张全平台、全状态的“统一任务清单”，显示总数、各来源数量及“来源平台”列。“查看全部任务”清除搜索和筛选；待办、逾期、临期与完成统计卡均显示全平台匹配任务。平台连接与同步默认折叠，出错时展开；“同步详情”分别显示三个平台的课程数、任务数、可用截止时间、入口及待核对数量。
5. 点击任务名称或“做题 / 提交”使用系统浏览器打开该任务。系统浏览器使用自己的登录状态；最终做题与提交由用户完成。

已连接平台在启动时及运行期间每 30 分钟同步。登录窗口打开期间每 5 秒检查登录变化；上一轮采集仍在运行时会排队检查。全局和单个平台自动同步开关均生效，“同步所有平台”可主动刷新并恢复统一视图。登录失效和重连不删除本地任务。

## 数据与状态

学生课程活动支持普通作业、测验和考试，以及章节中的作业、考试。读取任务名称、课程、开放时间、截止时间、平台状态、题目进度和成绩，不请求题目、答案或提交接口。

旧活动状态 0/1 为未作答/作答中，2/3 为已提交/已批阅；章节考试使用对应渲染器的状态规则，作业不套用考试数字状态。明确的文字、已提交和已完成字段优先。章节只有 `done/total` 时按题目进度展示状态，100% 显示“已完成（平台题目进度）”并提示到原平台核对提交记录。未知状态显示“状态待核对”；手动完成、忽略、被打回和恢复在后续同步中保留。

截止时间取具体任务字段，支持秒/毫秒时间戳和完整日期。无时区的完整日期按北京时间读取，统一以 UTC 保存、按本机时区显示。没有可用截止日期时保留未知并显示“平台未提供”，不以课程结束时间或成绩代替。可用日期参与 P0–P4 排序和提醒，成绩与百分比进度分开保存。

任务去重包含平台、站点、账号、班级、任务类型和任务编号，数据库只保存其摘要。两个平台分别使用 `.local/webview-profile-yuketang` 和 `.local/webview-profile-changjiang`，配置和同步结果独立保存。切换雨课堂站点先取消并等待旧请求结束；“重新连接”只清除当前平台会话。任务链接使用 Windows DPAPI 当前用户保护。

## 请求契约

请求路径和页面路由已对照公开官方客户端资源与参考实现；这些资源证据不能替代本人账号验证。全部为所选官方站点的 GET 请求：

| 数据 | 路径与参数 | 用途 |
| --- | --- | --- |
| 当前用户 | `/v2/api/web/userinfo` | 确认账号归属 |
| 学生课程 | `/v2/api/web/courses/list?identity=2` | 发现班级与课程名 |
| 班级信息 | `/v2/api/web/classrooms/{classroom}?role=5` | 核对班级、读取官方课程签名 |
| 题目进度 | `/mooc-api/v1/lms/learn/course/schedule` | 使用平台返回的班级和签名，`is_h5=true` |
| 活动列表 | `/v2/api/web/logs/learn/{classroom}` | `actype=-1&page=0&offset=20&sort=-1`，递增页码 |
| 章节元数据 | `/mooc-api/v1/lms/learn/course/chapter` | 课程提供章节内容时读取，`show_unpublished=0` |

`cid` 与 `classroom_id` 使用同一官方班级编号；`sign`、`uv_id` 和 `platform_id` 来自当前课程或所选登录会话。请求使用官方 Web 客户端静态头 `XTBZ: ykt` 和 `Xt-Agent: web`。不请求其他站点、答题页面或作业操作接口。未知跳转直接报错，不能当作成功空列表。

课程最多 200 门；活动列表每门最多 100 页，单轮最多 1200 次请求。生产请求间隔至少 150 毫秒，单次超时 25 秒、单轮超时 10 分钟、响应最多 4 MiB。章节遍历最多 10000 个节点、深度 12。分页循环、未知结构、限流和达到上限都会标明本轮覆盖不完整。
