# 平台入口核查

2026-11-03 学堂在线公开前端 1.6.376 核查确认：电脑端 `/login` 挂载默认隐藏的弹窗，连接入口改为官网首页，用户点击右上角“登录”。首次打开和重试仅清理页面磁盘缓存，保留 Cookie 与登录存储；脚本、样式、空壳、网络和浏览器故障明确显示，后台状态不能覆盖。已根据官方公开脚本允许明确的 hCaptcha 与腾讯验证码内嵌文档路径，主页面、弹窗和任务读取范围保持原有官方限制。公开脚本核对和本地回归不能替代真实官方登录验收。最新发布与验证计数见 [开发进度](开发进度.md)。

2026-11-01 完成旧版 U 校园弹窗诊断恢复检修，正式库已确认 3 门班课、7 条测试同步成功。学生页先出现被拦截弹窗、随后后台确认会话时可清除当前错误，窗口提前关闭也会恢复；登录页、主导航、内嵌验证页和资源故障继续保留。智慧树此前已接入新登录中心、Polymas SSO、弹窗导航、页面缓存刷新及脚本失败检测，本人登录恢复仍待核对；公开资源中的旧脚本 HTML 回退尚不能证明是真实登录失败原因。

其他平台保存的任务路由按钮改为“打开官方任务”。界面只确认启动了官方入口，保留可能需要登录、核验或继续跳转的提示；缺少已确认地址时显示“入口待核对”。学习通仍按响应头确认的任务跳转显示做题、查看或提交记录。网页壳返回 HTTP 200 和本地回归通过均不能代替真实账号最终页面验收。

本地检查使用独立任务库、专用 WebView profile 和本地响应，系统浏览器仅捕获打开参数。历史智慧树公开资源研究不带账号或会话，U 校园会话研究只读课程与任务元数据。本轮正式状态直接读取用户程序此前保存的数据库记录，不请求官网或解密任务入口；最近记录中智慧树为 ZHS001、学堂在线为 XT001，需本人官方登录。开发与构建保留正式任务库和登录环境。
