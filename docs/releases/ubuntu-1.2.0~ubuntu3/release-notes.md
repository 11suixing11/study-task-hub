# Ubuntu 开发预览 1.2.0~ubuntu3

按大陆本科常用学年和上下学期生成选课预勾选草稿，再由用户审查确认或添加手动课程。

- 上学期按 9 月至次年 1 月，下学期按 2–8 月；学年与学期可切换。
- 根据课程名/说明中的明确学期、官网进行中状态和本地记录展示推荐理由。信息不明的可用课程预勾并放入待审查，其他学期和已结课课程降低优先级；存在本地待办时提示核对。
- 本学期主动排除的课程会记住，后来新发现的课程不会被误记为用户已排除。
- 支持搜索、采用建议、取消全部勾选、跨学期草稿和自定义手动课程。
- 预勾选及添加先保留在内存草稿，确认后通过同一事务保存课程、选择、学期与审查范围。旧 Revision 被拒绝并保留输入，取消不会写入自定义课程或创建任务。
- 用户确认后，存在已选官方课程时进入采集。自定义课程作为手动课程记录，可用于手动任务。

最终通过 199 项 Linux 核心断言、47 项共享移动检查、32 项 Python/GUI/安装包测试；实际旧 `ubuntu2` 包到新包的隔离前缀升级通过。包内源码核对、Wayland 1×→2×→1×、WebKit 2× 和性能验证绑定当前包哈希。

学期识别基于已有元数据，不能保证每个平台提供学校真实校历。信息不明时明确提示审查。本人官网账号、GNOME 通知目视、Ubuntu 24.04 和本机正式系统安装仍未验收，目前按开发预览交付。

使用方法见 [Ubuntu 安装与使用](../../Ubuntu安装与使用.md)；包、源码提交、依赖、哈希与范围见 [verification.json](verification.json)。智能选课截图位于项目 `artifacts/linux/verification/smart-courses/semester-recommendations.png`，采用独立合成数据。
