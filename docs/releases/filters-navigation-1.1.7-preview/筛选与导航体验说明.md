# 筛选与导航体验说明

Windows / Android 1.1.7 筛选与导航测试版；Android 内部版本号为 8。

## 按需要查看任务

两端首页支持组合使用状态、截止时间、平台、课程、搜索和排序，并显示当前匹配数量。例如，可同时选择“已完成”和“已逾期”，查看已经完成但截止时间已过的任务。

Windows 点击任务首页筛选栏“更多”展开时间与课程条件；Android 点击“更多筛选”展开条件，搜索框与这些条件一起生效。Windows 点击“查看全部任务”、Android 点击“清除筛选”，可清除搜索和各项筛选。

截止时间提供今天、未来 7 天、未来 30 天、已逾期、24 小时内、无截止时间、时间未知和自定义日期：

- “今天”按本机日历日判断，包含今天已经到期和即将到期的任务。
- “未来 7 天”包含今天剩余时间及之后 6 天；“未来 30 天”包含今天剩余时间及之后 29 天。这两项排除已经逾期的任务。
- 自定义范围按本机日历日判断，可只填开始日期或结束日期；结束日期包含当天全天。
- 日期格式错误或开始日期晚于结束日期时，页面会解释原因，修正后再应用。

## Android 返回与退出

系统返回键、边缘返回手势和页面返回按钮使用一致的业务导航：任务详情回任务首页，截止时间编辑回原详情，官网登录回该平台管理页。在平台或设置根页按返回，先回任务首页。

在任务首页第一次按返回会提示“再按一次返回键退出”，2 秒内再次返回才退出；超过 2 秒需重新按两次。切换页面或在前台、后台之间切换后，会重新等待两次返回。退出保留本机记录。

Windows 延续一个主窗口内的页面跳转，平台管理、官网登录、选课、任务编辑和设置都在该窗口内完成。接入及完整同步成功后回任务首页；扫码后尚未确认登录或读取未完成时，页面会说明原因及下一步。

## 自动隐藏已结束课程

选课列表默认隐藏有可信依据的已结束课程，可切换“显示全部课程”或“仅看已结束课程”，也可组合课程搜索。判断依据目前为：

| 平台 | 可信依据 |
| --- | --- |
| 学堂在线 | 官网课程状态明确已结课 |
| MOOC | 当前开课期的结束日期已到 |
| 智慧树智慧课程 | 课程目录中的结束日期已到 |

其他平台或结束信息未知的课程继续显示。不会根据任务逾期、没有待办、课程名称中的年份或课程未出现在目录中，推断课程已经结束。

成功取得该课程的新信息后，若课程已续期、重新开课，或本轮结束信息不明，会更新判断并恢复显示。刷新失败或本轮目录未出现该课程时，沿用上次信息；可切换“显示全部课程”核对。

自动隐藏只改变选课列表，保留原有同步选择和历史任务。全选、全不选只影响当前可见列表，隐藏课程的勾选保持。需要停止同步某门已结束课程时，请显示全部课程，取消该课程勾选并保存。
