# Windows 1.1.8 PTA 接入修复测试版

PTA 官网确认账号后，Windows 可能仍停在通行证页面，旧的 PTA003 提示也会盖住已经取得的课程和任务结果。本版在同一主窗口、同一登录环境中尝试恢复到固定官方课程主页；当前账号和官网主页都得到确认后，再推进选课或回到任务首页。

首次接入先选择要同步的课程。官网主页加载较慢时，已保存的选择和本轮任务结果会等待主页完成，随后自动回首页。等待期间重新修改课程选择或历史任务显示选项，会保留当前页和未保存的改动；再次保存后继续。已保存会话的普通平台管理流程，在完整同步后直接回首页。

PTA 登录成功与任务完整读取分别展示。部分题目集或答卷状态没有确认时，首页显示已读取数量、同步未完整确认的原因和重试入口。新的官网页面、验证窗口、网络、证书或运行错误仍会阻止自动返回，并显示在当前选课页。重新登录、会话变化、取消和旧检查结果不能触发跳转。

Windows 仍使用一个主窗口，保留状态、时间、平台、课程组合筛选和默认隐藏有可信结束依据的课程。Android 保持已交付的 1.1.7，本轮没有修改 Android。

本轮复核 4 个受影响 Windows 项目，构建零警告、零错误；业务检查按原有统计口径为 3,211 项，桌面与会话重启检查 928 项。PTA 返回专项为 34 个场景、68 项断言，包含在 114 项 PTA 桌面检查内。全部使用合成数据和本地响应；没有重新运行全部 11 个 Windows 项目。

新包另核对随包运行时、许可、图标、逐文件 SHA256、ZIP CRC 和独立 EXE 的资源及空测试数据库初始化。本轮没有执行 Setup 或安装升级，也没有代替本人进行真实账号扫码、验证码授权、正常主窗口目视验收或长期登录体验。正式启动指针、正在运行的程序、任务库和登录环境保留。

便携包完整解压后，从原程序主界面点击“退出程序”，再运行“启动独立测试.cmd”；右上角 × 仅隐藏到托盘。独立入口使用包内空测试数据，仍遵守单实例。Setup 由本人手动运行会更新已安装程序。
