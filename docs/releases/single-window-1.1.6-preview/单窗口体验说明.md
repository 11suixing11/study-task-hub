# Windows 1.1.6 单窗口测试版

2026-11-15 本地交付。Windows 正常业务只保留一个主窗口，平台管理、官网登录、选课、任务编辑、设置、同步详情、提醒记录、首次说明及操作确认在主窗口内部跳转。延续 1.1.5 的扫码接入解释和学习通作业／考试独立读取修复。

## 接入和返回首页

从首页左侧选择平台，在平台管理页打开官方登录。本人扫码并在官方 App 确认授权后，接入卡自动检查，也可点击“我已扫码，检查接入”。学堂在线从官网右上角“登录”进入官方弹窗。

| 本轮结果 | 程序行为 |
| --- | --- |
| 首次确认官网登录及完整课程目录 | 自动进入主窗口内课程选择页，勾选课程后点击“保存选择并采集”。 |
| 已有确认的课程选择 | 接入检查通过后自动同步已选课程，无需再次选课。 |
| 登录已确认、登录保存成功、课程与任务范围完整读取 | 自动返回统一任务首页，显示同步任务数量。 |
| 完整返回空课程目录 | 自动回首页，明确说明官网当前没有课程。 |
| 登录未确认、保存失败、课程或任务未完整读取 | 留在当前页给出原因、诊断编号和下一步，保留已经读取的任务。 |

扫码或已有 Cookie 不直接算接入成功。网络、超时、官网限制、权限、额外验证、组件失败和未知结构继续分开解释。每个平台在本机只保存本人一份当前登录。

## 在一个窗口内操作

页面上方“返回”或 Esc 回上一页，“任务首页”回任务清单。左侧可直接进入另一平台或设置。返回重开复用当前官网登录页面、Cookie 和本机 profile；组件失效时重新进入会重建并给出原因。窗口大小、最大化状态和任务详情的显隐偏好保持。

离开接入流程后，旧回调和后台结果不会把新页面强制切回首页。删除或清理的确认也在主窗口内显示，返回或离开即取消。退出先取消并等待同步、保存登录状态，再释放页面；保存遇到问题时在主窗口内提示。

任务名称和“打开官方任务”继续使用系统浏览器，答题与提交由本人在官网完成。右上角 × 隐藏到托盘，切换版本前需点击首页“退出程序”。启动前无法加载数据库、参数错误或重复实例仍可能显示系统启动提示。

## 自动验证及其范围

完整回归构建 11 个项目，零警告、零错误，3,092 项业务、1,381 项桌面／导航／会话／重启、63 项 Python 诊断通过。首页及单窗口流程 288 项，含 36 组导航生命周期和 11 组 WebView 接入链路；这两组每步均检查只存在一个主窗口。八个自动平台的 24 个布局场景通过控件、滚动和官网登录区域尺寸检查，保存 32 张截图。

真实产品控件预览另有 26 项检查通过，覆盖八个平台的图标、最小尺寸、课程搜索与批量选择、编辑校验、保存按钮和空清单恢复。预览工具改为读取内部页面的实际尺寸，并按 Windows 的自动平台支持范围运行，原有布局和交互断言保留。

安装验证使用相同脚本和相同交付 payload 的 `TestInstallation` 隔离变体，检查 1.1.2→1.1.6 升级、合成库和加密存档导入、冲突保留、profile 保留及排除导入、卸载保留外部数据。交付 Setup 本身未直接安装实测。便携 ZIP 检查 CRC、全部文件哈希、独立资源及数据库启动。10 个依赖、21 个许可来源文件哈希、.NET／WindowsDesktop 10.0.13 和十档嵌入图标随包核对。

验收使用独立任务库、profile、合成 HTTP 和 WebView 响应，未访问官网账号或操作真实手机。原始报告保留在本地构建目录，随包摘要移除本机绝对路径；结果及文件哈希见 [脱敏验证摘要](verification.json)。真实扫码授权、验证码、长期登录、各平台当前课程与任务、官网最终页面和可靠目视验收仍待本人核对。
