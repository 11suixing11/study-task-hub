# 聚合平台 1.1.2

Android 学习通扫码确认后出现“该登录跳转尚未适配”时，本版将旧 HTTP 返回和新窗口导航等价升级为 HTTPS，保留路径、参数和片段，并补齐课程域名与路径作用域的 Cookie 读取。二维码清理失败会保留记录，下次启动重试。Android 内部版本号为 4；Windows 安装版与便携版同步更新到 1.1.2，包含最新桌面源码和统一托盘主图标。

- Android：`StudyTaskHub-1.1.2-Android.apk`，Android 9+，沿用旧版签名。
- Windows 安装版：`StudyTaskHub-1.1.2-Setup-win-x64.exe`，Windows 10/11 64 位，含 .NET 10.0.13。
- Windows 便携版：`StudyTaskHub-1.1.2-Portable-win-x64.zip`，完整解压后运行“启动聚合平台.cmd”。
- 中文说明、`SHA256SUMS.txt`、验证摘要及 Android 第三方许可 ZIP 随附件提供。Windows 第三方许可已包含在包内。

手机直接覆盖安装后，重新打开官方登录并保存新的二维码，在学习通内扫码确认，再返回聚合平台点击“登录完成并读取课程”。最终 APK 重复安装的数据恢复已验证；旧内部版本号 3→4 直接升级尚未实测。保留手机数据时不要先卸载。

Windows 升级前在旧版点击“退出程序”；关闭窗口会隐藏到托盘。安装版与便携版继续使用当前 Windows 用户的数据目录，升级与卸载保留数据。缺少 WebView2 时由安装向导安装官方运行时。

Android 16 项登录跳转与课程会话检查、47 项共享及 47 项原生合成检查、重启、最终包重复安装、页面和二维码流程验证通过。Windows 11 个项目、2,996 项业务、1,157 项桌面与重启、40 项 Python 检查通过；便携 ZIP 的 523 个文件哈希、CRC 和隔离启动通过。安装、1.1.1→1.1.2 升级和导入实测使用同脚本、同 payload 的隔离 TestInstallation 变体，交付 Setup 本身未直接安装实测。完整范围见附带验证摘要。

真实手机学习通扫码后课程读取尚未复验，官方 App 相册识别、新版真实账号、最终官方任务窗口和目视验收仍待完成。原生一键授权未接入，官网扫码仍需本人确认；Root 提取功能延期。Windows 与 Android 分别保存任务和登录，暂无跨设备同步。PTA 失效删除归档及提前关闭漏存的既有问题仍待修复。
