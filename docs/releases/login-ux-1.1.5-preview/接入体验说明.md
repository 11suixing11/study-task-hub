# 1.1.5 接入体验测试版

2026-11-15 本地交付 Windows 1.1.5 安装版与便携版、Android 1.1.5（VersionCode 7）。本轮针对“扫了码却不知道是否接入、为什么失败”的反馈，提供分阶段结果、原因和下一步，并整合学习通作业／考试独立读取修复。

项目用于本人官网登录后，只读同步已选课程的任务，在统一首页提醒，再到官方平台答题与提交。Windows 和 Android 各自保存本人登录与任务，每个平台使用一份当前账号。Linux 是本次审阅修复的开发环境，项目没有 Linux 使用端。

## 扫码后如何判断

打开平台管理中的“连接平台”，在应用内官网登录；扫码后在官方 App 确认授权，回到聚合平台等待官网返回。程序自动检查，也可点击“我已扫码，检查接入”。学堂在线先从官网右上角“登录”进入官方弹窗。

| 接入卡结果 | 含义和下一步 |
| --- | --- |
| 官网仍要求登录 | 官网尚未认可当前登录；核对官方授权、验证码及官网返回后重新检查。 |
| 登录已确认，课程读取未完成 | 身份通过，但课程服务读取失败；按卡片原因处理，再重试课程读取。 |
| 已接入，待选择课程 | 登录与完整课程列表已确认；点击“选择课程并同步”，勾选课程后“保存选择并采集”。 |
| 已接入，官网当前没有课程 | 本轮完整返回空课程目录；可在平台管理刷新课程复核。 |
| 已接入，任务同步未完成 | 已选范围存在读取失败；已读任务与个人修改保留，按提示重试。 |

扫码、打开官网首页和存在 Cookie 各自都不足以证明接入成功。网络、超时、权限、官网限制请求、额外验证、页面加载和未知返回分别给出原因与操作建议；不完整课程或任务响应保留为“未完成”。“接入检查详情”显示检查时间、计数、诊断编号和结果类别。

Windows 在左侧显示可滚动引导和详情，官网在右侧保留高度。Android 检查成功后保留官网，等待本人点击“选择课程并同步”继续。两端重新打开官方登录都保留现有登录；Windows 的本平台清理按钮直接清理，Android 清理前需本人确认。清理保留任务、选课与个人标记。
