# Ubuntu 开发预览 1.2.0~ubuntu4

修复任务状态切换的界面问题。

- 窄窗口中打开详情后，切换状态筛选导致原任务不再匹配时，收起空详情面板，解除覆盖新任务清单的遮罩。
- 详情的任务状态菜单只提供五种合法任务状态，并跟随当前选中任务显示；“全部状态”只作为首页显示筛选。
- 支持选择待办并保存，正确将已完成任务恢复为待办。
- 保留智能学期选课、手动课程、任务编辑、登录、采集和提醒。

新回归覆盖五种状态/全部状态筛选、窄窗口任务被筛掉时的面板收起、详情状态绑定和完成→待办。最终通过 199 项 Linux 核心断言、47 项共享移动检查、35 项 Python/GUI/安装包测试。实际旧 `ubuntu3` 包到 `ubuntu4` 的隔离前缀升级、加密数据和 profile 保留通过；包内前端与测试源码逐文件核对。

显示回归使用本机 Wayland。终端继承的旧 Xwayland 认证路径导致一个额外提示，验证使用原生 Wayland 并移除测试进程的 X11 连接环境，不关闭任何认证或导航校验。

仍为 Ubuntu 26.04.1 amd64 开发预览。本人官网账号、GNOME 通知目视、Ubuntu 24.04 和本机正式系统安装仍未验收。包、哈希、源码提交和逐项结果见 [verification.json](verification.json)，使用方法见 [Ubuntu 说明](../../Ubuntu安装与使用.md)。
