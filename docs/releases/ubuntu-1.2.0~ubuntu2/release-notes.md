# Ubuntu 开发预览 1.2.0~ubuntu2

修复登录关闭与后台恢复的实际竞争问题，并补齐旧包升级、实际 Wayland 输出切换和性能验证。

- 关闭登录窗口复用正在进行的采集，关闭/超时后拒绝旧指纹和保存回调；不会在窗口关闭后启动新同步。
- 编辑、设置、平台和登录窗口可恢复后台；已加载输入保留，旧响应和旧 job 不再影响恢复后的界面。
- 退出采用统一等待预算，无法响应的登录窗口也会结束，后台不再追加固定两秒等待。
- 安装 `io.github.studyTaskHub.desktop`，匹配 GApplication 与通知身份；升级移除旧桌面入口。
- 用真实已校验 `ubuntu1` 包升级到 `ubuntu2`，验证任务、加密链接、会话、设置、课程配置和 profile 文件保留。

最终源码验证通过 162 项 Linux 核心断言、47 项共享移动检查和 28 项 Python/GTK/WebKit/安装包测试。包内前端逐文件与测试源码核对，当前包包含自包含 .NET 运行时及依赖许可。

实际 Wayland 1×→2×→1× 输出切换通过；测试使用自身窗口的 `fullscreen_on_monitor`，没有执行人工拖动。WebKit 2× 本地页面通过可见内容检查并保存 3840×2400 截图。截图仅包含自身测试窗口，不含桌面其他应用。

5,000 条、每条 4,000 字备注且无链接的独立任务首屏查询为 0.7540、0.6628、0.6322 秒；包内进程冷启动到已映射首页为 0.9598 秒。本轮数据达到 2 秒查询、3 秒启动目标；该数据集不代表所有真实账号和任务组合。

Ubuntu 26.04.1 amd64 为实测平台。安装/重装/跨版本升级/卸载使用 fakeroot 独立 dpkg 前缀，依赖按本机版本另行核对。本人官网账号、GNOME 通知目视、Ubuntu 24.04 和本机正式系统安装仍未验收；目前按开发预览交付。Ubuntu 24.04 环境准备受当前 Docker/管理员权限限制，未绕过权限或宣称已验证。

包、SHA256、源码提交、依赖、图片及范围见 [verification.json](verification.json) 和 [release-assets.json](release-assets.json)。启动与安装方法见 [Ubuntu 使用说明](../../Ubuntu安装与使用.md)。旧版包与记录保留在历史目录。
