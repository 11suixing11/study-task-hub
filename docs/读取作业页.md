# 读取并保存学习通作业

适用于 Windows 本地版的高级诊断。正常使用在首页点击“连接学习通”完成登录后即可自动采集课程与作业，见 [自动同步](自动同步.md)。以下手动步骤用于核对单个页面；已完成作业也可用于核对。

日常打开作业直接点击首页的任务名称，或选中任务后点击“做题 / 提交”。程序确认该任务入口后交给系统浏览器；已提交任务打开查看或提交记录。系统浏览器使用自己的登录状态；手动诊断窗口用于元数据核对。

1. 双击项目目录中的 [启动聚合平台.cmd](../启动聚合平台.cmd)，首页点击“连接学习通”，展开“高级诊断与手动读取”。
2. 点击“打开官方登录”，自行扫码或登录。窗口沿用项目内独立会话；普通浏览器的登录不会自动带过来。更新程序无需清除登录数据。
3. 在采集窗口进入本人课程的“作业”列表，等待加载完成。
4. 点击“读取当前作业页”，核对名称、数量和平台显示状态。读取范围为主页面及最多 12 个已加载内嵌页面，每页最多 500 条，不自动翻页。
5. 可填写“课程名称”，点击“保存到任务清单”。保存中会显示按钮状态，完成后显示新增、更新、重复行数量。没有可用任务标识的条目每次保存可能重复，需在首页核对。
6. 选中一条作业，点击“在验证窗口打开选中作业”，核对课程与作业一致。“在系统浏览器打开”使用浏览器自己的登录状态。
7. 在详情再次点击“读取当前作业页”，查看作答开始、结束时间原文，再点击“保存时间原文到这条任务”。须先保存该任务的列表记录才能关联详情。
8. 回到首页，查看自动生成的截止日期及依据；年份推定或剩余时长估算会标明，可在编辑中确认后安排临期、逾期提醒。平台完成、提交和待批阅会归入完成，原始标签仍单独显示；你手动修改的状态和日期保留。

如果提示“没有找到可识别的已加载作业列表或详情”，等待页面加载后重试。未知页面、登录失效、结构变化不代表没有作业。限制和缺失项会显示在读取结果中，无需复制整页、Cookie 或账号参数。

官方 HTTP 链接会保留原路径和参数改用 HTTPS。主页面、新窗口及内嵌页面都处理；反复降级会停止，并保留提示。不忽略证书错误。任务具体入口来自列表外层 `li[data]`，内部“智能分析”链接不作为作业入口。

读取弹窗是临时结果，页面导航或关闭后清除。点击保存后，任务和时间原文保存在 `.local/data/tasks.db`，退出重启仍可查看；导航不删除已保存任务。任务直达链接使用当前 Windows 用户的 DPAPI 加密保存，诊断报告不包含账号编号、签名链接、Cookie 或页面正文。

首页关闭后保留托盘提醒与学习通定时同步；点击“退出程序”停止。通知实际显示受 Windows 设置影响，可在“设置与平台”发送测试提醒核对。本版尚无开机自启、独立后台服务或 Android 应用；学习通自动采集的完整覆盖仍需真实账号验收。

开发验证入口：`scripts/build.ps1` 执行构建与合成检查；`scripts/test-work-pages.ps1` 启动全部资源本地响应的独立 WebView 测试窗口；`scripts/test-dashboard.ps1` 使用独立合成数据库验证清单和重启恢复。合成验收与真实账号验收分开记录，详见 [开发进度](开发进度.md)。
