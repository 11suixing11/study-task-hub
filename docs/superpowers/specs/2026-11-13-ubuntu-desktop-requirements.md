# 学习任务聚合平台 Ubuntu 桌面版需求文档

- 版本：1.0
- 日期：2026-11-13
- 状态：技术方向已确认，本文作为 Ubuntu 首版的需求与验收依据。

执行计划：[Ubuntu 桌面版实施计划](../plans/2026-11-13-ubuntu-desktop-implementation.md)

## 1. 目标与用户

为当前使用 Ubuntu 的个人学生提供可安装、可日常使用的学习任务聚合应用，包含任务界面、手动管理、本人官方登录、选课、八个平台已支持的元数据采集及本地提醒。

首要交付是在用户的 Ubuntu 26.04.1 amd64 / GNOME 50 / Wayland 环境中验证过的 `.deb` 安装包。Ubuntu 24.04 amd64 是兼容验证目标，未实际验证时只能标注“待验证”，不能宣传为已支持。

用户已决定先制作 Ubuntu 完整应用。此前“局域网任意两台设备对等同步”的需求保留，排在 Ubuntu 首包之后，使用独立计划实施。

## 2. 已确认环境与全局约束

以下约束编号供执行计划原样引用。

- **G01：首要验收平台为 Ubuntu 26.04.1 amd64、GNOME 50、Wayland；Ubuntu 24.04 amd64 的兼容性必须独立验证。**
- **G02：前端使用 Python 3.12+、GTK 4.14+、libadwaita 1.5+、WebKitGTK 6.0 API 2.44+；后端使用 .NET 10、net10.0、linux-x64。**
- **G03：复用现有任务领域、存储与平台解析/采集代码；不将 WPF、WebView2 或 Android UI 依赖引入 Linux 核心。**
- **G04：前后端使用当前用户的子进程标准输入输出协议，不开启 HTTP 监听服务，不引入云账号或云服务。**
- **G05：数据默认位于 XDG_DATA_HOME/study-task-hub；未设置 XDG_DATA_HOME 时使用 ~/.local/share/study-task-hub。测试必须使用独立 --data-root。**
- **G06：应用数据根目录与浏览器 profile 目录权限为 0700，保护密钥文件权限为 0600；密钥和密文不可放入安装包或 Git。**
- **G07：保留正式任务库 .local/data/tasks.db 和既有登录环境；测试仅使用隔离数据库、隔离 profile 与本地响应。**
- **G08：用户本人完成官方登录；后台仅采集课程、任务及个人状态元数据，不代答题、不提交任务、不读取题目或答案正文。**
- **G09：人工修改优先；未知结构、分页上限、登录失效不能当作没有任务；平台原始状态和时间依据必须保留。**
- **G10：诊断仅记录错误码、计数、操作名和结果；不记录 Cookie、密码、票据、token、带签名参数的完整 URL 或 IPC 消息正文。**
- **G11：应用运行时自动采集与提醒可用；关闭应用后停止。首版不增加开机自启、常驻系统服务或跨设备同步。**
- **G12：交付自包含 .NET 运行时的 amd64 .deb；系统 GUI、WebKit、SQLite 与运行库依赖必须在包元数据中声明。**
- **G13：沿用当前项目目录作为开发工作区，使用功能分支；默认不启动子代理，除非用户明确要求。**

本机已探测到 Python 3.14.4、GTK 4.22.4、libadwaita 1.9.1、WebKitGTK 2.52.6、系统 SQLite 3.46.1、.NET SDK 10.0.404。当前缺少 `gir1.2-webkit-6.0`，需通过正式依赖解决。用户有 1× 与 2× 两块显示器，并偏好深色主题。

### 3.1 字段与时间规则

沿用 `TaskRules.Validate`：标题最多 300 字，课程/成绩最多 200 字，备注最多 4000 字，进度 0–100，手动优先级 P1–P4 或自动。采集任务不能更换来源平台。链接必须符合现有完整 HTTPS 校验。

内部日期使用带时区的 ISO 8601 / UTC；界面按系统本地时区展示和输入。手工选择日期不能使用无时区字符串传给后台。缺年份、倒计时估算及无时间情况沿用原始证据规则；推定日期不能未经确认就触发定时提醒。

| --- | --- | --- |

| 雨课堂、长江雨课堂 | 课程活动、已支持作业/测验元数据 | 保留站点/账号/课程身份；专业版及特殊账号能力按现有契约和实测标注 |
| 中国大学 MOOC | 课程开课期作业、测验、新旧考试 | 必须取得官网账号上下文；未知个人状态显示待核对 |

## 4. 主要用户流程

**首次使用：** 安装 → 打开首页 → 本地任务可用 → 选择平台 → 本人官方登录 → 已保存并校验 → 查看课程 → 勾选并保存 → 采集 → 统一首页查看。

**日常使用：** 启动加载本地记录 → 恢复有效会话 → 按开关采集已选课程 → 保留人工修改 → 查看更新与覆盖限制 → 官方页面处理任务。

**手动任务：** 新增 → 填写字段 → 校验并保存 → 编辑/标记状态 → 提醒或官方跳转 → 确认删除。

**失败恢复：** 登录未确认、过期、网络错误、部分覆盖、后台退出分别显示原因 → 保留已有任务和输入 → 用户重试、重新登录或恢复后台。

首页空态区分初次使用、尚未确认课程、隐藏历史、筛选无匹配和采集未完整；只有明确完整且为零的结果才表示本轮没有任务。

## 5. 模块与通信契约

前端为 GTK 4 / libadwaita 应用，后端为自包含 .NET 子进程。LinuxCore 通过源码引用复用现有领域和同步器；Linux 专用保护、会话保存状态和平台地址适配封装在新增文件中，避免大规模迁移现有目录。

IPC 使用 UTF-8 JSON Lines，协议版本为 1；请求含 `id / version / command / args`，响应含相同 id 与 `ok / result` 或 `error.code / error.message`。长采集返回 jobId，另发 progress/job-finished 事件；取消请求必须能在采集进行时处理。

请求上限 2 MiB，响应上限 16 MiB；行读取须在分配前限制长度。未知命令、非法参数、协议版本不匹配均返回错误且不改变数据库。前端不把协议正文写日志。敏感会话仅通过当前用户的专用子进程管道用于恢复浏览器，不能通过命令行参数传递。

首页每页最多 100 条，响应携带 snapshotVersion；筛选改变或版本失效时丢弃旧页面响应并刷新，避免长列表和异步返回覆盖当前选择。

## 6. 非功能要求

- **性能：** 本机候选包冷启动到本地首页目标 3 秒内；5,000 条隔离任务的首屏查询目标 2 秒内；采集时编辑与取消仍可操作。记录实测，不伪造目标达成。
- **数据保护：** 密钥创建需原子写入；已有数据库但密钥丢失时禁止静默生成替代密钥。目录/密钥符号链接及越权访问需拒绝或明确报错。WebKit profile 由浏览器管理，不承诺其原始存储文件全部加密。
- **依赖：** LinuxCore 优先使用 `Microsoft.Data.Sqlite.Core` 与系统 SQLite provider；系统 SQLite 依赖最低 3.37。发布前审查托管与系统依赖，避免直接带入已发现的脆弱原生 SQLite bundle。
- **可诊断：** 保留发布证据、错误码、平台结果与时间；异常消息经过筛选，不输出敏感数据或未处理的崩溃堆栈。
- **兼容：** GTK/libadwaita/WebKit 调用遵守 G02 版本下限；Ubuntu 24.04 实际验收前，发布摘要明确未验证。

| A12 | 提醒 | 已确认日期触发；完成/取消选课取消待发项；通知失败保留重试；关闭程序后无服务继续运行 |

| A15 | 本人账号验收 | 本人完成指定平台登录、课程抽样、任务状态/日期/入口核对；未覆盖账号明确记为未验收 |
| A16 | 发布范围与回归 | Ubuntu 26.04、Ubuntu 24.04、fixture 与本人账号结果分别记录；既有可在 Linux 运行的共享检查通过；Windows 专用检查另列环境需求 |

候选包交付要求 U01–U18 实现，并且 A01–A14 中适用于本机 Ubuntu 26.04 的核心、GUI、WebKit fixture 与包检查全部通过；数据损坏、无法启动、核心任务管理失败或正式依赖缺失均阻止交付，不能以“兼容标记”替代通过。A16 的 Linux 共享检查与验证范围记录也必须完成。

A14 的实际安装、升级与卸载在可恢复的测试环境中验证，不能仅凭解包成功宣称已通过。若暂时没有此环境，可提供明确标为“解包预览”的产物供评估，但不能将其记为安装验收通过的候选包。A15 必须由本人操作；未完成时交付标为候选包，不能把 fixture 结果写成账号验证。Ubuntu 24.04 未验证不阻止仅面向本机 Ubuntu 26.04 的候选包交付。

## 9. 源码依据与已知风险

主要依据：`src/AccessProbe/TaskDomain.cs`、`TaskStore*.cs`、`TaskNavigation.cs`；`src/AccessProbe.Android/MobileSync.cs`、`MobileVault.cs`、`MobileSessionRules.cs`、`MainActivity.cs:202`；`tests/MobileChecks/MobileChecks.csproj`；`docs/安装与手机版.md` 与 `docs/登录状态已知问题.md`。

目前 Linux 已跑通既有 47 项共享移动隔离检查。ProbeChecks 的 Windows DPAPI 检查不能在 Linux 直接作为全套基线；这是环境边界，不应通过删除保护规则“修复”。已有 PTA 失效归档与提前关闭保存问题、WebKit 官网兼容性、Ubuntu 24.04 环境和混合 DPI 人工验收均需独立记录。
