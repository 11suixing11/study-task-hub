# Ubuntu 完整桌面版设计

状态：技术方向已确认。正式需求与验收以 [Ubuntu 桌面版需求文档](2026-11-13-ubuntu-desktop-requirements.md) 为准；本文保留前期设计与系统探测记录。

## 目标与交付

先交付面向当前 Ubuntu 26.04.1 amd64 主机的可安装 `.deb`，Ubuntu 24.04 amd64 为独立兼容验收目标。程序从应用菜单或 `study-task-hub` 启动，内置 .NET 10 运行时，无需用户安装开发 SDK。Ubuntu 24.04 未实测时不宣称已支持，不用当前主机结果代替。

本次先制作 Ubuntu 包，随后恢复局域网对等同步路线图。Ubuntu 应用本身暂不宣称已经实现设备同步。

## 推荐实现

- 根据本机探测，采用 Python 3 / GTK 4 / libadwaita 原生桌面界面，WebKitGTK 6.0 提供各平台独立官方登录窗口。该方案替代此前 GTK 3 + WebKitGTK 4.1 提案。
- 新增 .NET 10 Linux 业务核心和本机子进程桥接，复用现有 TaskDomain、TaskStore、各平台 HTTP 读取器/解析器/同步器以及已通过跨平台检查的会话规则。
- UI 与后台通过本机标准输入输出交换结构化消息，不开启本地 HTTP 服务，不依赖云账号。
- Ubuntu 本地 AES-GCM 保护适配器用于任务链接及登录归档；随机密钥保存在当前用户私有数据目录，目录 0700、密钥 0600。WebKit profile 亦位于同一私有目录下，各平台独立。
- 数据默认位于用户数据目录 `~/.local/share/study-task-hub`，测试通过独立 `--data-root` 隔离。首次启动不读入 Windows 项目的正式数据库或登录环境。

## 首版行为

1. 统一首页显示全部平台任务，提供搜索、状态筛选、截止排序、统计、任务详情和官方任务跳转。
2. 支持新增、编辑、完成、忽略、删除手动任务，保存备注、日期、成绩、进度与优先级；遵循既有领域校验和人工修改优先规则。
3. 平台管理显示学习通、雨课堂、长江雨课堂、中国大学 MOOC、学堂在线、智慧树、旧版 U 校园和 PTA；FiF 保留手动模式。
4. 用户在 WebKit 官方页面自行扫码或账号登录，应用读取允许作用域的 Cookie 并加密保存；登录、课程目录读取、确认选课、采集任务分别提供明确操作与状态。
5. 调用现有八个平台的元数据采集逻辑，保留来源、时间依据、覆盖限制和未知结构错误；不能将读取失败表述为无任务。
6. 应用运行时定期采集已确认课程，并检查本地提醒；提供系统通知开关。关闭 Ubuntu 应用后采集与提醒停止，首版不增加系统后台服务。
7. Linux 浏览器与既有 Windows/Android 登录环境独立。官网若限制 WebKit 登录或票据到期，明确显示该平台原因；真实账号验收仍由本人完成。

## 文件与边界

- `src/AccessProbe.LinuxCore/`：共享领域源码引用、本地保护、Ubuntu 应用服务。
- `src/AccessProbe.LinuxBackend/`：结构化消息入口与核心调用，输出错误码和经过筛选的用户提示。
- `src/AccessProbe.Linux/`：GTK 首页、任务编辑、平台管理、WebKit 登录、通知与桥接。
- `tests/LinuxChecks/`：密钥保护/重启、任务 CRUD、选课、会话存储和消息协议的隔离行为检查。
- `tests/test_linux_ui.py`：实际 GTK 交互与本地 WebKit fixture 检查；不访问官方账号。
- `scripts/build-linux.sh` 与 `packaging/linux/`：自包含 publish、桌面入口、依赖声明、图标和 deb 打包。
- `docs/Ubuntu安装与使用.md`：安装、数据目录、官网登录、覆盖边界与验收结果。

## 验收与限制

- 隔离数据库验证新增、编辑、状态变化、删除、重启与课程选择持久化。
- 密钥权限、跨实例解密、密文篡改拒绝和不同密钥拒绝均有行为测试。
- 实际 GTK 页面检查筛选、编辑保存、平台入口和正确错误状态；WebKit 使用本地页面验证导航与 Cookie 桥接。
- 包解压后直接运行，确认不依赖仓库路径或 SDK；核对 `.deb` 元数据、桌面入口、运行时、依赖和 SHA256。
- 本机 Ubuntu 26.04 验证结果与 Ubuntu 24.04、真实各官网登录分别记录；未运行的范围标注未验收。
- 不修改现有官方平台请求契约，不代答题或提交，不将 Cookie、票据或页面正文输出到诊断日志。

## 本机系统基线与适配要求

本次只读探测结果：

| 项目 | 实测结果 |
| --- | --- |
| 操作系统 | Ubuntu 26.04.1 LTS，Resolute Raccoon，amd64 |
| 内核 | 7.0.0-43-generic |
| CPU | AMD Ryzen 9 9955HX 16-Core Processor，32 个逻辑 CPU |
| 内存与磁盘 | 约 30 GiB 内存，约 150 GiB 文件系统剩余空间 |
| 桌面 | GNOME Shell 50.1，Wayland，偏好深色主题 |
| 显示器 | 2560×1440 / 1×；1920×1200 逻辑尺寸 / 2× |
| 显卡 | NVIDIA GeForce RTX 5070 Ti Mobile 与 AMD Radeon 集成显卡 |
| Python | 3.14.4 |
| GTK | GTK 4 4.22.4 与 GTK 3 3.24.52 均已安装 |
| libadwaita | 1.9.1，Python GI 接口可用 |
| WebKit | WebKitGTK 4.1 和 6.0 运行库均为 2.52.6；4.1 GI 可用，6.0 GI 尚未安装 |
| .NET | 本轮已在项目 `.tools/dotnet` 准备 SDK 10.0.404 / Runtime 10.0.15；尚无 Android workload |

包架构使用 amd64，优先在本机 Ubuntu 26.04 验收。GTK 4 界面遵循系统深色偏好，并检查窗口在 1× 与 2× 显示器之间移动后的布局、文字和图标。WebKit 按原生 Wayland 路径集成，实际登录窗口渲染后再评估显卡兼容性，不预先强制显卡或禁用加速。

新增运行依赖需包含 `gir1.2-webkit-6.0`，其余 libadwaita/GTK/Python GI 依赖按 deb 正式声明；不能依赖开发时的临时环境变量。Ubuntu 24.04 兼容设计限定使用其已提供的 GTK/libadwaita API，并单独验证，不能仅凭本机较新的库版本宣称兼容。
