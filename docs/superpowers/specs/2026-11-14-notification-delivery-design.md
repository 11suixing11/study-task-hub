# 桌面通知结果与重试

补齐已授权 F08。当前 Gio.Application.send_notification 异步调用没有服务端回执，不能立即当作成功。Ubuntu 改用 org.freedesktop.Notifications.Notify 的异步 D-Bus 回执；只有返回通知 id 才记录“桌面已接收”。是否在屏幕显示仍由系统通知设置决定，界面明确区分。

调度器等待发送 Future 再确认提醒；连接失败记录 NOTIFY003，拒绝或超时记录 NOTIFY004，其他发送错误 NOTIFY001。失败提醒保持可重试，一分钟后自动重试，并可在设置中立即重试失败项；已接收项不重发。停止调度释放尚未确认的领取，迟到回调不确认已释放项。

设置中的通知状态窗口显示最近 500 条提醒状态、尝试次数、错误与接收时间，提供测试提醒、刷新、立即重试失败项。测试提醒结果单独持久化，不创建正式任务。发送请求和实际显示不混为一谈。

验证通过独立 D-Bus 服务测试真实异步调用、服务接收与拒绝，不使用真实账号。调度集成用真实后台数据库和未完成 Future 复现提前 ack，再验证失败与重试；系统桌面实际显示仍是人工验收项。
