# 自定义课程管理

依据已授权功能清单 F04，在现有 SQLite / LinuxCore / GTK 流程中补齐管理。

课程保留不随改名变化的 key。旧课程沿用已有 key；新课程使用随机本地身份派生的 key。Linux 专用登记包含名称、学期和归档标记，保存在 settings；旧版课程说明可迁移，任务原来的名称派生关联在管理事务中转为明确 key。

修改名称与学期时，课程目录、登记与关联手动任务在同一事务内更新；任务 Revision 增加，旧编辑窗口会收到冲突。归档保留全部历史任务，移出已选课程并停止其提醒；恢复归档后由用户重新选课。有任务的课程禁止移除，入口说明可归档；空课程移除需要确认。

任务编辑器选择来源平台后可选择已登记、未归档课程，也保留自由输入。保存时后台在事务中核对课程归属与归档状态，并使用登记名称。采集任务原有官方课程身份保持，不能改为其他登记课程。

“平台与课程”提供自定义课程管理，FiF 手动模式也能添加/管理课程。变更刷新首页及课程页面，恢复后台后重新读取数据，不接受旧连接回调。

验证使用隔离数据库：旧课程改名不丢任务；同名新增不会复用改名课程身份；学期编辑、归档、恢复、空课程移除与旧 Revision 冲突；真实 GTK 编辑选择后任务绑定保持。正式数据库和浏览器环境不参与验证。
