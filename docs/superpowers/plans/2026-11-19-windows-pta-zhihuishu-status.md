# PTA／智慧树 Windows 接入状态修复计划

> 行为范围：Windows 本地测试版；按现有隔离合成回归验证，不提交、不推送、不切换正式版。

**目标：** 让账号验证、课程目录、支持范围内的任务读取与单项核对分别显示。未选课仍由用户决定，手动状态优先，不放宽官网导航验证。

**事实与判定：** PTA 的题目集目录、账号及课程选择都已确认，部分完成状态或个人时间不能确认；只有所有已选题目集列表均已读、且仅有详情待核对时，才显示“题目集已读取，答卷或时间待核对”。智慧树仅在作业、考试列表均已读，且唯一问题是其他学习活动不在范围时，提示支持范围内已同步并说明遗漏数量。遇到网络、分页、未知结构或账号归属问题继续报告不完整；真正失效才引导重登。

- [x] 先在 `ConnectionFeedbackChecks`、`PlatformAccessPresentationChecks` 以合成成绩摘要复现：PTA 不能标作完整或需要重连；智慧树不能把明确未覆盖类型报成失败；混合实际错误不得降级为范围说明。通过 `ProbeChecks` 观察现有行为失败。
- [x] 在 `ConnectionReports.From(MetadataSyncSummary, ...)` 输出已证实的窄范围事实；`TaskStore.Connection` 有界保存。由 `WindowsConnectionFeedback` 产生状态、说明及恢复动作，平台卡、接入中心和首页复用；仅有范围说明允许按支持范围返回首页。最后一次任务结果可作为历史说明，不能替未经验证的当前账号作担保。Android 不改展示行为、不重出包。
- [x] 在 `PtaSyncHarness` 先复现“重试同步”实际未读答卷、已恢复页面仍显示旧警告；再把 `MetadataConnectionPage` 按钮接到真正的方法。保留实际导航失败及历史诊断，已经恢复时立即清理旧 UI 文案。
- [ ] 运行 `scripts/build.ps1 -VerifyOnly`，检查完整回归报告，再从通过的构建制作独立 Windows 测试包，核对 ZIP 完整性、发布文件一致性与隔离初始化。真实账号与直接安装留待试用，不覆盖上轮测试包。
