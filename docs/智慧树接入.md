# 智慧树接入

Windows 版本已接入智慧树官方登录、翻转课、共享课、智慧课程及 AI 智课／智能体课目录。新版智慧课程在选课后读取未完成和已完成作业、考试；共享课包含机房考试、在线补考及可确认身份的线下安排。课程与任务汇入首页同一清单，保留平台状态、截止日期、时间依据和可确认的官方入口。2026-11-03 已用现有 Cookie 只读核对新版智慧课程与作业，最终官方界面和用户选课后同步仍待验收。

## 使用

从左侧打开智慧树平台管理，点击“连接平台”完成官方登录；没有页面跳转时仍检测会话变化。登录确认后保存最新 Cookie，先列出翻转课、共享课、进行中和已完成智慧课程及 AI 智课／智能体课。智慧课程的课程 ID 与班级、共享课的课程 ID 与开课期共同隔离，并绑定当前账号。勾选并点击“保存选择并采集”后，只抓取已选课程任务。新安装及旧配置迁移均需确认范围，新增课程不会自动选中；开启自动同步后在启动时及每 30 分钟更新已选课程。

平台管理集中提供连接、刷新、选择、同步、停止与自动开关，支持缩放和收起课程区，没有多用户选项。“刷新课程列表”只更新目录，失败时保留已有目录、选择与明确错误。

最新 Cookie 用 Windows DPAPI 当前用户加密保存到任务库 `platform_sessions` 表，旧 `.local/sessions/zhihuishu.bin` 兼容迁移。启动与连接默认恢复有效 Cookie，保留官方有效期，不额外设置 30 天期限；HTTP 续期写回原环境和仓库。辅助 `acw_tc` 变化不再误判换号，学生主页面令牌绑定当前认证 Cookie 和来源。明确失效保留密文仅供官方复核，不能直接标为已登录；明确清除登录数据才永久移除凭据。关闭连接窗口立即保存新认证 Cookie，官方账号复核成功后再标为已登录。旧响应不能覆盖新会话。

2026-11-04 排查反复 `ZHS001`：HTTP 403、Missing JWT 及模糊服务错误与明确未登录分别分类；权限或课程令牌不足保留当前 Cookie。连接窗口仍未出现可识别的官方账号信息时，继续等待登录，不反复发送未登录检查，也不使用旧页面令牌激活会话。登录与元数据诊断只增加操作名称、结果、HTTP 状态和固定会话变更原因，不记录凭据、标题或响应正文。北京时间 22:08:33（14:08:33 UTC）的只读检查中，正式仓库为过期状态且无可用登录 Cookie；需要本人在新版连接窗口完成官方登录。修复已发布于 `20261104-141231-e33d6dad` 并完成隔离回归，不能宣称真实账号已恢复。见 [开发进度](开发进度.md)和 [只读诊断](../artifacts/releases/20261104-141231-e33d6dad/verification/platform-errors-readonly-checks.json)。

官网已从旧 passport 入口切换到 `login.zhihuishu.com` 登录中心。新版保留学生首页回跳，并允许 `cloudapi.polymas.com/oauth/login/ssoLogin` 与 `checkLogin` 的已确认官方返回目标。该中转域仅用于登录导航，不作为任务数据或会话归档来源；弹窗在事件结束后继续导航。打开登录窗口及点击“打开官方登录”会刷新 WebView2 页面磁盘缓存，保留 Cookie、localStorage 和已取得的课程页面令牌。“重新连接”仍表示主动清除该平台会话。见 [平台入口核查](平台入口核查.md)。

“刷新课程列表”只刷新目录。“同步所有平台”读取已选课程任务；取消选择会停止该课程的任务采集与提醒，已有任务保留，可重新勾选恢复。“同步详情”显示课程目录、已选课程、实际读取课程、任务数量及覆盖限制。

## 覆盖范围

| 类型 | 已接入 | 限制 |
| --- | --- | --- |
| 智慧课程目录 | 进行中、已完成两类完整列表，保留同课不同班 | 旧版入口及未知版本仍列出，但任务未适配会明确标注 |
| 新版智慧课程任务 | 作业、考试的未完成与已完成列表，与任务类别 count／unfinished 核对 | 学习资源、讨论、智能体和其他任务只报告未覆盖数量；互评、小组、矛盾状态待核对 |
| AI 智课／智能体课目录 | 官方 AI 目录及已确认分页 | 此类课程的任务接口未确认，不能把未适配解释为没有任务 |
| 翻转课目录 | 学生翻转课课程列表及已确认分页 | 未识别结构、重复页、页数变化与读取上限均报告部分覆盖 |
| 翻转课任务 | 课程内作业、考试列表，按官网每页 20 条读取所有状态 | 互评和未知任务结构需官网核对 |
| 共享课目录 | 在学、已完成两类目录，按官网每页 5 门读取 | 课程 ID 与开课期共同隔离；不同账号独立 |
| 共享课作业 | 未提交、已提交两类列表 | 每类读取官网首批最多 100 条；接口提示还有更多时明确报告未完整覆盖 |
| 共享课线上考试 | 线上期末考试的状态、日期及归属元数据 | 进入考试须在官网完成核验，当前没有直接答题入口 |
| 共享课机房考试 | 学校机房考试的状态、日期及已确认的考场安排 | 按官网区分未提交、已提交；过期不表示已交卷，考场未安排时保留学校安排说明 |
| 共享课在线补考 | 机房课程明确有补考时读取线上考试列表 | 补考标识未知时报告部分覆盖，保留已确认机房数据和历史补考 |
| 共享课线下考试 | 有完整考试标识时记录学校安排事项 | 状态与日期均待核对，不采用未经官网确认的额外日期，不提供答题入口 |
| 首页提醒 | 翻转课近期事项补充、共享课聚合提醒数量 | 提醒消失不表示任务完成，聚合数量不转换为虚构任务 |

每类分页最多 100 页，单轮最多 600 次元数据请求。未知结构、接口限流、账号归属变化和读到上限都保留已有任务并提示原因；零条解析结果不能直接解释为没有作业。目录完整与任务列表完整分别记录，只对已选课程计算任务覆盖。机房和线下返回必须是可识别的单对象、明确 null 或空对象；缺少考试标识的安排只计入“安排记录未导入”，不制造任务。列表遍历完整与状态、日期、入口待核对分别统计。

## 状态、时间和入口

完成状态依据课程任务列表中的官方提交字段，未提交、退回和待核对分别保留。任务列表确认的状态优先于首页提醒；列表暂时失败或提醒消失不会将已完成任务恢复为待办。用户手动修改的状态、日期、课程名和备注继续优先。

新版智慧课程 `examStatus=5/6` 与已完成列表一致时才确认完成；`7` 表示逾期未提交，保留待办，`10` 退回保留需重做。互评、小组、未知或矛盾状态保留待核对。原 `endTime` 截止与 `latestSubmitTime` 补交、`peerReviewEndTime` 互评时间独立保存，不采用课程结束时间或后续窗口替换作业截止。

开放时间和截止时间取自具体任务字段，保留时间依据；未知、格式异常或矛盾时间不猜测。机房考试按官网中国文本时间读取，日期倒置时待核对；学校未明确安排考场时不使用额外地址。线下考试仅提示学校安排，状态与日期均保持待核对。课程结束日期不会代替作业截止日期。可用截止时间参与统一优先级排序和提醒。

翻转课作业按官网 `homeworkDetail` 路由打开；未提交或退回的翻转课考试只有官网允许进入时才提供验证入口。共享课作业按学生作业记录与原始状态校验具体地址。点击任务或“打开官方任务”时从任务库读取最新链接，由系统浏览器打开；浏览器仍可能需要官方登录、核验或继续跳转。已校验路由与归属不能代替最终页面的真实账号验收。

共享课线上考试和在线补考先经官网身份、地点或验证码核验，再获得进入考试所需的另一种标识。当前保留列表元数据及核验说明，不把列表 ID 拼成直接答题地址；请从官网共享课考试列表进入。机房与线下考试保留学校安排说明。后台不执行考试核验、不读取作答正文、不提交答案。

新版智慧课程打开官网 `/singleCourse/taskAndExam/{courseId}/{classId}` 任务列表，官方 `taskType` 筛选作业或考试；附带采集任务标识以核对保存入口的归属，不宣称官网已定位某条作业。用户按任务名进入，官网自行进行必要核验。后台仅请求任务类别和两个提交状态列表，不调用 `startPullPaper`、`openExam` 或补卷接口。

## 会话与故障

2026-11-07 新增官方续期：学生短期 token 失效时先不带该 token 复核 CAS 账号；同账号成功后当前读取器不再附带旧 token。CAS 会话失效时检查官网 `user.zhihuishu.com/zhsuser/login/isLogin` 的 CASTGC 有效状态，有效则沿 passport → 官方 Polymas 登录中转 → 学生首页的确认 GET 链路续期，再不带旧 token 复核同一账号。最多 8 跳、严格白名单，CAS Cookie 和课程 token 不传给 Polymas。续期及一次同账号重试计入单轮 600 次请求上限；网络失败报告复核不可用并保留凭据，明确换账号仍停止，权限 403 不清登录。

11 月 7 日对正式安装数据的只读核对确认：旧版已清空智慧树加密凭据，profile 仅有辅助 Cookie。新版无法重建已删除的 CAS 登录；升级后需首次在连接窗口本人登录。两平台续期、异常保留、关闭窗口保存和跨进程恢复已完成合成回归，但智慧树真实账号续期尚未验收，不能用 U 校园真实成功或历史智慧树成功替代。

智慧树使用独立 WebView2 登录目录与 Windows 当前用户 DPAPI 加密归档。恢复保留平台有效期，续期和删除写回同一登录环境；重连、注销、取消或退出会停止并等待旧请求。首页和共享课任务请求分别使用官网对应的加密参数。

公开资源核对发现，部分旧登录脚本的地址现在返回 HTTP 200 的 HTML 回退页，当前发布脚本正常返回 JavaScript；浏览器缓存旧入口时可能出现空白。项目检测登录域 `/assets/*.js` 的失败状态或异常 MIME，并提示刷新页面。该机制处理一种已观察到的资源失败，尚不能断定是用户当前登录失败的原因。

登录窗口明确显示主页面、内嵌验证页、弹窗跳转、网络、证书及渲染失败；后台会话检查不再覆盖当前页面错误，重试后开始新的诊断。首页“同步详情”展示最近登录诊断，`.local/diagnostics/zhihuishu-login.json` 保存最多 24 条阶段事件及当前失败分类、Cookie 计数和账号/令牌是否出现，不保存凭据、身份值、原始 URL 或作答正文。未知学校 SSO 跳转仍报告尚未适配。

账号接口成功后独立确认登录，课程目录失败不要求重复登录；未知账号结构不能被标为登录已确认。平台卡片显示已登录待选课或课程刷新需核对。同步详情先显示当前会话与最近课程刷新，再显示明确标注的上次任务同步；历史 ZHS001 不覆盖当前成功登录。官网现有三个目录的明确空返回已核对：翻转课零页及零总数、共享课 `courseOpenDtos=null` 且总数为零、AI 目录零 page／size／total／totalPage 且空数组。缺字段、非零总数、后续页提前为空仍报错。

当前 qiankun 学生主页面的 `localStorage.token` 与旧 iframe 来源分别识别，只读取精确官网 origin／path；有效主页面令牌优先，旧 iframe 空值或旧令牌不覆盖它。令牌为可选凭据，其缺失不直接表示智慧课程未登录。页面超时绑定导航 ID，只有该导航实际成功才恢复；脚本、证书、内嵌页和渲染错误不会被后台成功抹去。

| 错误码 | 处理 |
| --- | --- |
| ZHS001 | 官方复核及续期后仍明确失效，或旧版已清空凭据时，在连接窗口重新登录；已有任务保留 |
| ZHS002 | 登录页面或脚本加载失败时点击“打开官方登录”重试；任务读取失败时查看同步详情 |
| ZHS003 | 元数据、归属或部分字段未确认，核对官网课程；不能当作没有任务 |
| ZHS004 | 会话保存或清理失败，检查本地目录权限；重启可能需要登录 |
| ZHS005 | 限流、分页重复或读取上限，当前覆盖未确认 |
| ZHS006 | 智慧课程其他任务、旧版课程或 AI 智课任务未覆盖，或共享作业更多记录、考试标识未确认；按提示核对官网 |

## 验证

智慧树、旧版 U 校园与 FiF 停用策略的业务检查覆盖四类目录、大整数标识、课程与班级隔离、分页、三种加密模块、账号隔离、状态优先、手动保留和未知结构。`MetadataSyncHarness` 另验证新版智慧课程、两平台官方续期及回存、旧 token 回退、拒绝后凭据复核、关闭窗口前保存和跨进程恢复。最新计数与证据见 [开发进度](开发进度.md)。历史 2026-11-04 全组 1,106 项业务、231 项桌面和 126 项重启检查见 [历史发布验证](../artifacts/releases/20261104-141231-e33d6dad/verification/verification.json)。

当前发布与检查计数见 [开发进度](开发进度.md)。历史发布 `20261029-173347-61572129` 完整构建通过 2,228 项业务和 849 项桌面、重启检查，其中本组业务 874 项、桌面 169 项、重启 126 项。见 [历史完整验证](../artifacts/releases/20261029-173347-61572129/verification/verification.json)和 [公开资源证据](../artifacts/releases/20261029-173347-61572129/verification/zhihuishu-public-resource-checks.json)。这些回归验证代码处理故障与重试的能力，用户真实登录是否恢复仍待确认。

2026-11-03 的历史正式库 Cookie 只在内存解密，通过实际产品读取器只读确认账号与六组目录：翻转 0、共享 0、智慧课程 3、AI 智课 0；进行中的智慧课程返回未完成作业 1 条、已完成 4 条，五条均有可用截止与校验通过的官方列表入口。官网另有资源学习任务 6 条，未伪造为作业。该历史诊断未写正式库、会话、选课或浏览器环境，报告仅保留计数和结果。见 [历史实际读取器核对](../artifacts/releases/20261103-153056-69c9477a/verification/zhihuishu-product-readonly-checks.json)。11 月 4 日最新会话已过期，不能用该历史成功替代当前登录；用户需在新版本人登录、刷新课程并勾选，最终官网页面待验收。
