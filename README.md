# 学习任务聚合平台

Windows 本地版本，C# / .NET 10 / WPF / WebView2 / SQLite。已接入学习通、雨课堂、长江雨课堂和中国大学 MOOC 的官方登录后自动采集；启动时与运行期间每 30 分钟更新。首页默认将全部平台、全部状态的任务显示在同一张清单，统一排序、统计与同步。前三个平台当前账号正式库为学习通 27 条、雨课堂 0 条、长江雨课堂 1 条。MOOC 独立只读诊断已识别 18 门课程和 120 条任务，修复版真实入库验收待切换后继续。其余四个平台支持手动录入。

项目已安装并默认启用 CodeGraph 1.6.2，开发时先用它理解和定位源码，遥测关闭；使用方法见 [CodeGraph](docs/CodeGraph.md)。

## 启动

双击 [启动聚合平台.cmd](启动聚合平台.cmd)。首页自动检查学习通及已连接平台的会话；首次使用点击相应“连接”按钮完成官方登录，随后自动采集。启动入口使用 `artifacts/current.json` 指向的检查通过版本。旧版仍在运行时，启动入口会保留中文版本提示；先在旧版点击“退出程序”，再双击此入口，关闭窗口只会隐藏到托盘。

独立 .NET SDK 与依赖位于项目 .tools 目录；第一次从干净目录构建需要联网还原 NuGet 依赖。需要 Windows 10/11 和 WebView2 运行时。本版本没有 Android 应用。

## 第一次使用

1. 点击“连接学习通”“连接雨课堂”“连接长江雨课堂”或“连接中国大学 MOOC”，在官方页面完成扫码或账号登录。雨课堂还可选择标准站点 `www.yuketang.cn` 或专业版 `pro.yuketang.cn`；使用本人课程所在的官方站点。
2. 登录后等待自动采集。程序自动识别课程名并导入作业，无需逐个打开课程、手动读取或保存。
3. 首页默认显示“统一任务清单”，同时汇总全部平台和全部状态，显示总数、各来源数量及“来源平台”列。平台筛选为可选项；“查看全部任务”清除搜索和状态、平台筛选。待办、逾期、临期与完成统计卡均查看全部平台的匹配任务。“平台连接与同步”和所选任务详情默认折叠，同步出错时自动展开平台详情。
4. 点击列表中的任务名称即可直达；也可选中任务后点击“做题 / 提交”。系统浏览器打开相应任务的官方做题、提交记录或查看页面。已完成任务显示“查看作业”，也可手动忽略、恢复或标记被打回。
5. “设置与平台”可关闭全局或单个平台自动同步；“同步所有平台”刷新学习通及已连接平台，并恢复统一清单。“同步详情”分别显示四个平台的结果。其余平台可通过“新增任务”录入。

作答区间按北京时间读取；缺少年份时显示完整日期并标注“年份推定”。列表只提供剩余时长时，按实际读取时间换算截止日期并标注“约”。这些日期参与优先级和到期筛选；推定或估算日期在编辑中核对确认后才安排定时提醒。平台没有提供任何可用时间时显示“平台未提供”。

课程名、备注、成绩、进度与优先级均可编辑。采集任务可在编辑中点击“更换链接”，粘贴新的完整 HTTPS 地址；取消保留原链接。搜索匹配任务名称、课程、平台或备注。状态筛选可查看完成、忽略和被打回任务；删除会弹确认，删除后无法恢复。

任务直达遵循 PRD 使用系统浏览器。学习通点击时从正式任务库读取最新链接，使用采集会话确认该任务入口的官方跳转，只读取响应头；保留签名参数，校验课程、班级、cpi、作业和已知答卷归属。雨课堂、长江雨课堂及中国大学 MOOC 使用已校验归属的具体任务路由；打开前读取最新链接，不请求作答正文。做题和提交由你在官方页面完成。系统浏览器沿用自己的登录状态，未登录时仍需官方登录；不会复制采集会话到日常浏览器。手动维护的链接直接打开。

平台进度是百分比，成绩是分数。采集任务若有真实进度且不足 100%，须核对或修正后才能手动标记完成；没有进度值时允许手动标记。明确的完成、提交和待批阅标签自动同步状态；手动完成、忽略、被打回和恢复会保留，不被后续平台同步覆盖。

## 学习通自动采集

- 学习通使用项目自己的登录环境；官方 Cookie 用 Windows 当前用户加密保存，重启前恢复缺失且未过期的 Cookie，保持平台原有效期与临时会话属性。后台收到续期或删除 Cookie 时写回同一环境。现有 profile 出现不同值时优先当前登录，避免混用旧会话。
- 退出程序时先停止并等待同步请求，再保存登录状态；“清除登录数据”和官方明确判定失效时清除恢复归档。旧版已经丢失的临时 Cookie 无法补回，第一次切换若仍提示 `SYNC001`，需完成一次官方登录。平台注销或到期仍可能要求重新登录。
- 登录窗口打开期间检查会话变化，包括登录成功但主页面没有跳转的情况；登录完成与上一轮读取重叠时，会排队继续采集。
- 自动发现课程并逐门读取作业，课程名、平台显示状态、直达地址和作答时间原文自动保存；明确的状态自动映射，可用时间转换为截止日期。
- 已适配课程入口到新版课程页的跳转，以及作业详情到查看页、提交提示页的跳转；明确显示“暂无作业”的课程正常计入已读取数。
- 详情转入作答页时保留列表任务；提交提示页没有作答时间时，保留列表时间。“同步详情”分别说明这两类结果。
- 已保存任务按课程、班级、cpi、work ID 去重；刷新签名链接时保留用户修改和手动状态。
- 自动跟随已识别的课程/作业分页链接；达到读取上限或分页契约未识别会直接显示 `SYNC007`，不能视为完整清单。
- 单轮最多 200 门课程、每个列表 20 页、100 条详情、600 次请求。其余详情后续轮次继续读取；详情 24 小时内缓存，列表每轮更新。
- 登录过期时保留任务并显示 `SYNC001`，在“连接学习通”重新登录后继续自动采集。
- 自动采集只读，真实账号的课程完整性、签名时效及年份/时区仍需核对。具体请求契约见 [自动同步](docs/自动同步.md)。

2026-10-23 当前登录账户已读取 15/15 门课程，正式库保留 27 条作业和 19 条作答时间原文。新版已修正为 24 条完成/已提交、3 条待办；25 条显示截止日期，其中 19 条年份推定、6 条根据剩余时长估算。3 条待办距离截止均超过 24 小时，自动优先级为 P3；完成任务不显示待办优先级。2 条提交提示没有提供可用截止时间。该结果对应当前账号和本轮页面；后续新作业、其他账号与分页仍需核对。

## 高级诊断与手动读取

1. 首页点击“连接学习通”，展开“高级诊断与手动读取”。扫码、密码和验证码由你自行完成。
2. 在该独立窗口进入本人课程的作业列表，点击“读取当前作业页”。
3. 在读取结果中可填写课程名称，然后点击“保存到任务清单”。批量保存放在后台执行，按钮显示保存中，完成后显示新增与更新数量。
4. 选择作业，点击“在验证窗口打开选中作业”，再读取详情，可“保存时间原文到这条任务”。
5. 保存后自动显示截止日期及时间依据；年份推定或剩余时长估算会明确标注。可在首页编辑任务，确认日期后安排提醒。

这一手动入口仅覆盖当前已加载的主页面与最多 12 个内嵌页面；单页最多 500 条。它不自动遍历课程或翻页；空白、未知结构和登录失效不能解释为没有作业。正常使用由首页后台自动采集。

具体作业链接取列表外层 li[data]，不会使用“智能分析”地址。每次打开前验证链接结构。官方 HTTP 导航保留原路径和参数改用 HTTPS，循环降级会停止；不会忽略证书错误。

本地去重用同一课程 / 班级 / cpi / work ID 的观察组合，不按名称合并；签名更新和 answer ID 变化会更新链接，保留手动状态、截止时间和编辑字段。该组合仍需真实跨会话样本验证，不能当作跨账号身份的普遍保证。没有可用标识的作业会保留为独立任务，多次保存可能重复，请在清单中核对。

新版本读取结果可以保存到数据库；页面跳转只清除临时读取结果，不删除已经保存的任务。

## 数据与提醒

- 数据库：.local/data/tasks.db。任务与配置仅保存在本地。
- 独立学习通会话：.local/webview-profile。不会读取你平常使用的浏览器 Cookie。
- 学习通会话归档：.local/sessions/chaoxing.bin，仅使用 Windows DPAPI 当前用户加密；不保存账号密码。恢复保留 Cookie 原有效期，归档距保存超过 30 天不恢复；清除登录数据同时删除归档。诊断只记录保存/恢复结果，不记录 Cookie 值。
- 雨课堂会话：.local/webview-profile-yuketang；长江雨课堂会话：.local/webview-profile-changjiang。“重新连接”只清除选中平台的登录数据，保留任务。
- MOOC 会话：.local/webview-profile-mooc；加密归档：.local/sessions/mooc.bin。保持平台 Cookie 原有效期与临时属性，距归档超过 30 天不恢复；官方确认失效和重新连接清除归档。
- 所有任务直达链接使用 Windows DPAPI 当前用户保护后保存；账号签名不写入诊断报告或源码。任务标题、课程和备注为本地普通数据库字段。
- 复制项目到另一 Windows 用户时，链接可能无法解密；重新读取列表可更新，其他任务信息仍可查看。
- 时间按 UTC 保存与计算，界面按本机时区显示。
- 待办自动优先级：已逾期 P0；2 小时内 P1；24 小时内 P2；更晚或手动确认无截止时间 P3；无可用截止时间 P4。年份推定和剩余时长估算参与计算，界面保留依据标记。手动优先级不覆盖未知截止 P4 或已逾期 P0；完成和忽略任务显示“—”。
- 定时提醒使用平台完整日期或手动确认的日期。推定或估算的日期可在编辑中勾选确认；仅修改备注不会自动确认时间。
- 临期提醒：截止前 24 小时。任务在此窗口内才录入时，下次检查提醒。
- 逾期提醒：截止后 2 小时。被打回任务也提醒；完成和忽略任务取消尚未请求的提醒。
- 手动改截止时间会替换待发计划；已经向系统请求过的同一截止时间提醒不重复请求。改成新的截止时间会创建新计划。
- 采集导入新任务时，通知开启会创建一次新任务提醒。
- 提醒每 15 秒检查。关闭首页会隐藏到托盘并继续运行；托盘双击或右键可打开首页。
- 点击“退出程序”停止提醒；本版本没有开机自启或独立后台服务。下次启动会补查仍适用的待发计划，已过期的“临期”提醒会丢弃，逾期提醒可补查。
- 通知记录“已请求系统通知”表示 Windows 接受了程序请求，不代表你一定看到提示。系统通知设置、免打扰等会影响显示，用测试提醒核对。程序不会更改 Windows 权限设置。
- “复制延期申请”只复制话术，由你自行发送给老师。
