## 启动

直接使用请下载 Release 中的安装程序或便携包，无需开发环境。下列项目启动入口用于已准备本地 SDK 和依赖的开发工作区；GitHub 下载的源码需要先按 [源码构建说明](docs/GitHub发布.md) 准备开发环境。

双击 [启动聚合平台.cmd](启动聚合平台.cmd)。首页先恢复各平台保存的 Cookie，再检查已连接平台；首次使用从左侧打开平台管理，点击“连接平台”完成官方登录，确认课程选择后采集任务。启动入口使用 `artifacts/current.json` 指向的检查通过版本。旧版仍在运行时，启动入口会保留中文版本提示；先在旧版点击“退出程序”，再双击此入口，关闭窗口只会隐藏到托盘。

Windows 安装版支持 Windows 10 1809 及以上的 64 位系统，已包含 .NET 运行环境；系统缺少 WebView2 时由安装向导联网安装。开发用的独立 SDK 与依赖位于项目 `.tools` 目录，首次构建需联网还原 NuGet 依赖。桌面构建检查使用 Python 3.9 或更高版本，安装和启动程序无需 Python。Android 安装版包含自己的运行环境，需可用的系统 Android WebView。

手机版在手机完成官网扫码或其他官方登录、勾选课程并同步任务。扫码辅助入口可保存二维码并打开官方 App，确认后返回读取课程。Cookie 使用 Android Keystore 加密保存，重启默认复用，明确失效时引导重新登录；Windows 与手机分别保存登录和任务，没有跨设备同步服务。手机版前台每 30 分钟检查已选课程，后台仅按系统调度检查已有提醒，可能延迟。真实手机的官方登录、相册识别、课程完整性和最终任务页面仍需本人核对。

## 第一次使用

下列首页名称对应 Windows 1.1.2 正式版。

1. 点击左侧本人课程所在的平台，打开该平台的管理窗口，再点击“连接平台”完成官方扫码或账号登录。已接入学习通、雨课堂、长江雨课堂、中国大学 MOOC、学堂在线、智慧树、旧版 U 校园与 PTA；雨课堂可选择标准站点 `www.yuketang.cn` 或专业版 `pro.yuketang.cn`。
   学堂在线进入官网首页后，点击官网右上角“登录”打开官方弹窗；页面空白或错位时，在连接窗口点击“打开官方登录”刷新页面缓存，Cookie 和登录存储保留。
2. 登录确认后自动保存最新 Cookie，并读取该平台支持的全部课程目录，包含没有任务的课程。勾选需要记录的课程，点击“保存选择并采集”；确认前只读取目录，确认后只采集已选课程的已覆盖任务。
3. 首页采用三栏布局：左侧提供任务分类和平台管理，中间默认汇总全部平台和全部状态，右侧显示所选任务的状态、截止时间和操作。“全部任务”清除搜索和状态、平台筛选；待办、即将到期、逾期与完成分类查看全部平台的匹配任务。顶部工具栏集中提供同步、新增、课程管理及面板显隐。同步摘要和“采集依据与完整详情”按需展开，原平台状态与时间始终保留；同步出错时自动展开平台详情。
4. 点击有已确认官方入口的任务名称即可打开；也可选中任务后在右侧点击“打开官方任务”。系统浏览器沿用自己的登录状态，可能需要官方登录、核验或继续跳转。学习通根据已确认跳转显示“做题 / 提交”或“查看作业”；缺少入口时显示“入口待核对”。智慧树共享课考试需从官网考试列表完成核验。标记完成和编辑直接在右侧操作，忽略、恢复、标记被打回等位于“更多操作”。
5. 平台管理集中提供连接、课程刷新、选择保存、同步、停止和自动同步开关，可拖动边缘缩放，点击“收起课程区”缩小窗口。“设置”保留全局开关；“同步所有平台”更新已连接平台的已选课程并恢复统一清单。“同步详情”保留结果与覆盖限制。八个平台均保留“新增任务”手动录入，FiF 不显示自动连接或同步开关。

## 选择记录课程

打开左侧平台管理，勾选需要采集和提醒的课程，再点击“保存选择并采集”。新安装与旧版配置迁移后均需确认选择，没有默认采集全部课程的选项；新增课程需要再次勾选。搜索和“全选当前列表”只作用于当前列表，“同步已选课程”会先保存该平台当前选择。各平台独立保存范围，没有账号切换或多用户管理。

未选课程停止任务采集和提醒，已有任务保留。首次确认选择前历史任务继续可见；确认后默认隐藏未选课程的历史任务，重新勾选可以恢复。关闭“隐藏未选课程的历史任务”后可查看历史，但不会恢复这些课程的提醒。“全部任务”清除搜索、状态与平台筛选，仍遵循已保存的课程选择。

“刷新课程列表”只更新课程目录，不读取作业或替换最近的任务同步结果。课程刷新会单独保存时间、结果和错误码，在平台管理、首页“同步详情”及重启后显示。登录失效时引导重新登录，成功后覆盖仓库中的旧 Cookie；网络失败或未知结构保留明确错误以及已有课程和选择。手动录入平台的课程来自本地任务。

作答区间按北京时间读取；缺少年份时显示完整日期并标注“年份推定”。列表只提供剩余时长时，按实际读取时间换算截止日期并标注“约”。这些日期参与优先级和到期筛选；推定或估算日期在编辑中核对确认后才安排定时提醒。平台没有提供任何可用时间时显示“平台未提供”。

课程名、备注、成绩、进度与优先级均可编辑。采集任务可在编辑中点击“更换链接”，粘贴新的完整 HTTPS 地址；取消保留原链接。搜索匹配任务名称、课程、平台或备注。状态筛选可查看完成、忽略和被打回任务；删除会弹确认，删除后无法恢复。

任务跳转使用系统浏览器。学习通点击时从正式任务库读取最新链接，使用采集会话确认该任务入口的官方跳转，只读取响应头；保留签名参数，校验课程、班级、cpi、作业和已知答卷归属。雨课堂、长江雨课堂、中国大学 MOOC、学堂在线、智慧树和 PTA 使用已校验归属的具体任务路由；打开前读取最新链接，不请求作答正文。界面确认已打开官方入口，最终页面还可能要求登录、核验或继续跳转。智慧树共享课考试保留状态、日期与官网核验说明，尚不提供直接答题地址。做题和提交由你在官方页面完成。系统浏览器沿用自己的登录状态，未登录时仍需官方登录；不会复制采集会话到日常浏览器。手动维护的链接直接打开。

平台进度是百分比，成绩是分数。采集任务若有真实进度且不足 100%，须核对或修正后才能手动标记完成；没有进度值时允许手动标记。明确的完成、提交和待批阅标签自动同步状态；手动完成、忽略、被打回和恢复会保留，不被后续平台同步覆盖。

## 学习通自动采集

- 学习通使用项目自己的登录环境；官方 Cookie 用 Windows 当前用户加密保存，重启前恢复缺失且未过期的 Cookie，保持平台原有效期与临时会话属性。后台收到续期或删除 Cookie 时写回同一环境。现有 profile 出现不同值时优先当前登录，避免混用旧会话。
- 退出程序时先停止并等待同步请求，再保存登录状态；“清除登录数据”和官方明确判定失效时清除恢复归档。旧版已经丢失的临时 Cookie 无法补回，第一次切换若仍提示 `SYNC001`，需完成一次官方登录。平台注销或到期仍可能要求重新登录。
- 登录窗口打开期间检查会话变化，包括登录成功但主页面没有跳转的情况；登录完成与上一轮读取重叠时，会排队继续采集。
- 自动发现课程，确认选择后逐门读取已选课程的作业，课程名、平台显示状态、直达地址和作答时间原文自动保存；明确的状态自动映射，可用时间转换为截止日期。
- 已适配课程入口到新版课程页的跳转，以及作业详情到查看页、提交提示页的跳转；明确显示“暂无作业”的课程正常计入已读取数。
- 详情转入作答页时保留列表任务；提交提示页没有作答时间时，保留列表时间。“同步详情”分别说明这两类结果。
- 已保存任务按课程、班级、cpi、work ID 去重；刷新签名链接时保留用户修改和手动状态。
- 自动跟随已识别的课程/作业分页链接；达到读取上限或分页契约未识别会直接显示 `SYNC007`，不能视为完整清单。
- 单轮最多 200 门课程、每个列表 20 页、100 条详情、600 次请求。其余详情后续轮次继续读取；详情 24 小时内缓存，列表每轮更新。
- 登录过期时保留任务并显示 `SYNC001`，打开学习通平台管理，点击“连接平台”重新登录；更新 Cookie 后继续读取目录或同步已确认的课程。
- 自动采集只读，真实账号的课程完整性、签名时效及年份/时区仍需核对。具体请求契约见 [自动同步](docs/自动同步.md)。

2026-10-23 的历史账户读取为 15/15 门课程、27 条作业和 19 条作答时间原文，当时为 24 条完成/已提交、3 条待办；25 条显示截止日期，其中 19 条年份推定、6 条根据剩余时长估算，2 条提交提示没有提供可用截止时间。10 月 28 日最新列表已读取 29 条作业：原有 27 条全部匹配，新增 2 条待办尚未入库；本次未读取详情或重新核实截止日期，当前优先级以启动后同步结果为准。

## 高级诊断与手动读取

1. 首页左侧打开学习通平台管理，点击“连接平台”，展开连接窗口的“高级诊断与手动读取”。扫码、密码和验证码由你自行完成。
2. 在该独立窗口进入本人课程的作业列表，点击“读取当前作业页”。
3. 在读取结果中可填写课程名称，然后点击“保存到任务清单”。批量保存放在后台执行，按钮显示保存中，完成后显示新增与更新数量。
4. 选择作业，点击“在验证窗口打开选中作业”，再读取详情，可“保存时间原文到这条任务”。
5. 保存后自动显示截止日期及时间依据；年份推定或剩余时长估算会明确标注。可在首页编辑任务，确认日期后安排提醒。

这一手动入口仅覆盖当前已加载的主页面与最多 12 个内嵌页面；单页最多 500 条。它不自动遍历课程或翻页；空白、未知结构和登录失效不能解释为没有作业。正常使用由首页后台自动采集。

具体作业链接取列表外层 li[data]，不会使用“智能分析”地址。每次打开前验证链接结构。官方 HTTP 导航保留原路径和参数改用 HTTPS，循环降级会停止；不会忽略证书错误。

本地去重用同一课程 / 班级 / cpi / work ID 的观察组合，不按名称合并；签名更新和 answer ID 变化会更新链接，保留手动状态、截止时间和编辑字段。该组合仍需真实跨会话样本验证，不能当作跨账号身份的普遍保证。没有可用标识的作业会保留为独立任务，多次保存可能重复，请在清单中核对。

新版本读取结果可以保存到数据库；页面跳转只清除临时读取结果，不删除已经保存的任务。

- 时间按 UTC 保存与计算，界面按本机时区显示。

- 临期提醒：截止前 24 小时。任务在此窗口内才录入时，下次检查提醒。
- 逾期提醒：截止后 2 小时。被打回任务也提醒；完成和忽略任务取消尚未请求的提醒。
- 手动改截止时间会替换待发计划；已经向系统请求过的同一截止时间提醒不重复请求。改成新的截止时间会创建新计划。
- 采集导入新任务时，通知开启会创建一次新任务提醒。
- 提醒每 15 秒检查。关闭首页会隐藏到托盘并继续运行；托盘双击或右键可打开首页。
- 点击“退出程序”停止提醒；本版本没有开机自启或独立后台服务。下次启动会补查仍适用的待发计划，已过期的“临期”提醒会丢弃，逾期提醒可补查。
- 通知记录“已请求系统通知”表示 Windows 接受了程序请求，不代表你一定看到提示。系统通知设置、免打扰等会影响显示，用测试提醒核对。程序不会更改 Windows 权限设置。
- “复制延期申请”只复制话术，由你自行发送给老师。
