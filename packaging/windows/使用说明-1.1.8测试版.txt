聚合平台 Windows 1.1.8 PTA 接入修复测试版

支持 Windows 10/11 64 位，.NET / WindowsDesktop 10.0.13 已随包提供。
本轮为 Windows 测试版，任务、课程选择和登录记录保存在本人本机。

PTA 登录与回到首页
1. 在首页左侧选择 PTA，进入主窗口内的平台管理页，点击“官方登录”或“打开当前登录”。
2. 在主窗口右侧 PTA 官网完成登录。扫码后请在官方 App 确认授权，并等待官网返回。
3. 左侧自动检查接入，也可点击“我已扫码，检查接入”。
4. 若官网已经确认账号，但网页停在百腾通行证或留下旧的 PTA003 跳转提示，程序会尝试回到 PTA 官方课程主页。恢复成功后，旧提示不再覆盖当前接入结果。
5. 首次取得完整课程目录时，选择要记录的课程并保存；已有课程选择时继续同步已选课程。
6. PTA 当前账号、登录保存和课程选择确认后，按本轮结果回到同一个主窗口的任务首页。
7. 任务只读取了一部分时，首页会说明“任务同步未完成”、已经取得的数量和需要重试的范围，不把部分结果说成全部同步成功。已有任务、课程选择和人工修改保留。

接入没有成功时
仅扫描二维码、打开通行证页面或存在 Cookie 不能证明账号已经接入。
官网仍要求登录、登录保存失败、当前课程目录未确认、页面网络失败或验证未完成时，页面会给出原因及下一步。
请先核对官方 App 授权、验证码和应用内官网返回，再检查接入；课程或任务读取失败时可稍后重试，无需立即清理已有登录。
新的页面错误仍会显示，旧的 PTA003 只在当前账号及官方主页恢复得到确认后清除。
题目集或考试由本人在官方平台作答与提交；本程序只读取课程、任务和官方状态。

继续在一个窗口内使用
平台管理、官网登录、课程选择、任务编辑、设置和同步详情均在主窗口内完成。
页面上方“返回”或 Esc 回上一页，“任务首页”回到首页；窗口大小和任务筛选保持。
首页可组合状态、截止时间、平台、课程、搜索和排序；点击“更多”展开条件，“查看全部任务”清除筛选。
选课列表保留默认隐藏有可信依据的已结束课程、显示全部课程及仅看已结束课程的功能；结束信息未知的课程继续显示。
课程筛选只改变列表显示，历史任务和同步选择保留。需要停止同步时，显示全部课程、取消对应课程勾选并保存。

便携测试版
完整解压 ZIP，保留 app 目录及其中全部运行环境和第三方许可。
建议双击“启动独立测试.cmd”，它使用解压目录中的“独立测试数据”，首次为空，需要重新登录体验。
独立数据入口仍受单实例保护。体验前，请由本人在当前已运行程序的主界面点击“退出程序”，等待保存结束；右上角 × 只会隐藏到托盘。
“启动聚合平台.cmd”使用当前 Windows 用户安装版的数据，切换前同样需要完整退出现有程序。
独立数据不自动导入原有账号、课程或任务；需要使用原记录时，请选择普通入口或由本人运行安装包。

安装版与保存记录
本目录的 Setup 由本人手动运行；它会更新当前 Windows 用户已安装的聚合平台程序。安装前请从原程序主界面退出。
安装版默认数据目录为 %LOCALAPPDATA%\LearningTaskAggregator\.local，升级和卸载设计为保留该外部目录。
同一 Windows 用户可在安装时导入旧项目记录；导入前须完整退出旧程序。
Cookie 和受保护任务入口不能直接迁移到其他 Windows 用户或 Android。

本轮验证范围
本轮只验证受影响的 Windows 项目及合成、本地响应场景，具体项目与数量见随包 verification.json。
新包检查覆盖 payload 与 ZIP 的 SHA256、ZIP CRC、第三方许可、随包运行时和图标资源，以及独立 EXE 的资源及空测试数据库初始化。
独立 EXE 检查使用 --verify-installation 入口，不运行正常主窗口或登录流程。
本轮未运行交付 Setup，未进行安装升级实测；包已生成不能等同于安装升级已经验收。
真实 PTA 账号扫码授权、验证码回流、官网最终任务页、长期登录、实际双击 CMD 和显示效果仍待本人体验核对。
本地交付不会自动替换正式启动指针或正在运行的程序。
第三方许可、限定范围的验证报告及 SHA256 清单随包提供。
