聚合平台 Windows 1.1.9 体验优化测试版

支持 Windows 10/11 64 位，.NET / WindowsDesktop 10.0.13 已随包提供。
本轮为 Windows 测试版，任务、课程选择和登录记录保存在本人本机。

本轮主要变化
1. 首页新增接入摘要条：未接入时提供“开始接入”；有平台需要处理时提供“查看需要处理的平台”；全部接入后显示最近同步结果。摘要可以关闭，不隐藏任何状态。
2. 平台卡与接入中心使用统一状态文案：未接入、需要重新登录、需要重试、已接入未选课程、正在同步、已同步 N 条任务；卡片提示（悬停文字）解释当前状态。未选择课程不再标为需要处理：显示中性的“已接入，未选课程”与“选择课程”动作，不使用警示色，也不计入首页待处理提示；接入和目录读取完成后不再自动打开选课页，何时选课由本人决定。
3. 连接页统一为单主按钮：每个状态只有一个主操作，例如“检查接入”“刷新登录页”“重新打开登录页”“确认课程并同步”“重试读取课程”“重试同步”；课程选择在可用时作为次级按钮出现。
4. 登录被拒、登录未确认、课程为空、课程读取失败、保存失败和同步未完成分别显示不同原因，并给出可执行的恢复动作；高级诊断仍保留在连接页折叠区域内。
5. 官网返回空课程目录时，连接页保留在当前上下文说明“已接入，官网当前没有课程”，可重试读取或返回首页；不再自动回首页并按成功处理。
6. PTA 官网明确失效时，本机加密登录归档保留仅供官网复核，默认不激活；在连接页重新登录即恢复使用。登录检查完成前提前关闭连接页，新完成的 PTA 登录会作为未验证凭据立即保存，重启后仍可用。
7. 显式“清除登录数据”仍永久移除该平台登录归档，任务、人工标记和课程选择保留。
8. 本轮显示修复：智慧树在支持范围内的作业、考试全部读取后，平台卡与连接页显示中性的“已接入，支持范围任务已同步”并说明未覆盖数量；只有真实读取失败才标红要求重试。PTA“题目集已读取，答卷待核对”提供可用的“重试同步”按钮，会真正重读答卷状态而不重开登录。连接页左栏收窄并把官网区域加宽，状态不再与页面提示重复堆叠；智慧树／PTA 页底部长段覆盖说明改为只在同步详情中查看。

接入主路径
1. 打开软件后先看到任务首页；未接入时点击首页“开始接入”，或从左侧选择平台。
2. 在主窗口右侧官网完成登录；扫码后请在官方 App 确认授权，并等待官网返回。
3. 左侧自动检查接入，也可点击主按钮检查；登录确认、登录保存和课程与任务读取满足条件后自动回首页。
4. 首次接入先选择要同步的课程并保存；已有选择时继续同步已选课程。
5. 题目集或考试由本人在官方平台作答与提交；本程序只读取课程、任务和官方状态。

接入没有成功时
仅扫描二维码、打开登录页面或存在 Cookie 不能证明账号已经接入。
页面加载失败给“重新打开登录页”；登录未确认给“刷新登录页”；登录已确认但课程读取失败给“重试读取课程”；课程为空、保存失败或同步部分完成各有对应动作。
已有任务、课程选择和人工修改在任何失败状态下保留。

继续在一个窗口内使用
平台管理、官网登录、课程选择、任务编辑、设置和同步详情均在主窗口内完成。
页面上方“返回”或 Esc 回上一页，“任务首页”回到首页；窗口大小和任务筛选保持。
首页可组合状态、截止时间、平台、课程、搜索和排序；点击“更多”展开条件，“查看全部任务”清除筛选。
选课列表保留默认隐藏有可信依据的已结束课程、显示全部课程及仅看已结束课程的功能；需要停止同步时，显示全部课程、取消对应课程勾选并保存。

便携测试版
完整解压 ZIP，保留 app 目录及其中全部运行环境和第三方许可。
建议双击“启动独立测试.cmd”，它使用解压目录中的“独立测试数据”，首次为空，需要重新登录体验。
独立数据入口仍受单实例保护。体验前，请由本人在当前已运行程序的主界面点击“退出程序”，等待保存结束；右上角 × 只会隐藏到托盘。
“启动聚合平台.cmd”使用当前 Windows 用户安装版的数据，切换前同样需要完整退出现有程序。
独立数据不自动导入原有账号、课程或任务；需要使用原记录时，请选择普通入口或由本人运行安装包。

安装版与保存记录
本目录的 Setup 由本人手动运行；它会更新当前 Windows 用户已安装的聚合平台程序。安装前请从原程序主界面退出。
安装版默认数据目录为 %LOCALAPPDATA%\LearningTaskAggregator\.local，升级和卸载设计为保留该外部目录。
Cookie 和受保护任务入口不能直接迁移到其他 Windows 用户或 Android。

全部 11 个 Windows 项目零警告、零错误；3,250 项业务、1,541 项桌面／导航／会话／重启及 63 项同步状态检查通过，构建 20261119-161849-5074cbdd，报告随包 verification 目录提供。
PTA 失效归档保留、连接页提前关闭保存、接入摘要、平台卡状态文案、连接页单主按钮、空课程目录、智慧树支持范围中性状态和 PTA 答卷重试均有对应专项检查。
新包检查覆盖 payload 与 ZIP 的 SHA256、ZIP CRC、第三方许可、随包运行时和图标资源，以及独立 EXE 的资源及空测试数据库初始化。

真实账号扫码授权、验证码回流、官网最终任务页、长期登录、实际双击 CMD 和显示效果仍待本人体验核对。
本地交付不会自动替换正式启动指针或正在运行的程序；正式启动指针保持 1.1.2。
