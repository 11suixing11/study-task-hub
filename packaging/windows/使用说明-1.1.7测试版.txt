聚合平台 Windows 1.1.7 筛选与导航测试版

支持 Windows 10/11 64 位，.NET / WindowsDesktop 10.0.13 已随包提供。
系统没有 Microsoft WebView2 时，安装向导会联网安装。
每个平台使用一份当前登录，任务、选课和登录保存在本人本机。

开始使用
1. 在首页左侧选择平台，进入主窗口内的平台管理页，点击“官方登录”或“打开当前登录”。
2. 在同一个主窗口右侧官网完成登录。扫码后需要在官方 App 确认授权，并等待官网返回。
3. 左侧接入卡自动检查，也可点击“我已扫码，检查接入”。
4. 首次登录和完整课程目录确认后，自动进入课程选择。勾选需要记录的课程，点击“保存选择并采集”。
5. 已有课程选择时，接入检查通过后自动同步已选课程，无需再次选课。
6. 登录已确认、登录保存成功且课程及任务范围完整读取后，自动返回首页，并显示同步任务数量。
7. 本轮完整返回空课程目录时，也会回首页说明“官网当前没有课程”。

在一个窗口内使用
平台管理、官网登录、课程选择、任务编辑、设置、同步详情、提醒记录和操作确认均在主窗口内完成。
页面上方“返回”或 Esc 回上一页，“任务首页”回到首页；左侧可直接进入另一平台或设置。
接入页离开后保存当前登录；同次运行重新进入会继续使用原有网页和登录环境。
浏览组件初始化或运行失败时，重新进入连接页会重建页面并给出原因。
主窗口大小及最大化状态保持；接入成功回首页时保留任务详情的显隐偏好。
任务名称和“打开官方任务”仍打开系统浏览器，答题与提交在官网完成。

任务筛选
任务首页可组合状态、截止时间、平台、课程、搜索和排序，显示当前匹配数量。
点击筛选栏“更多”展开截止时间与课程条件，可再次收起以保留任务清单空间。
截止时间提供今天、未来 7 天、未来 30 天、已逾期、24 小时内、无截止时间、时间未知和自定义日期。
今天及日期范围按本机日历日判断；未来 7/30 天包含今天剩余时间及之后 6/29 天，排除已逾期。
自定义范围可只填开始或结束，结束日包含全天；日期错误会解释原因并等待修正。
“已完成”可以与“已逾期”等时间筛选组合。点击“查看全部任务”清除搜索和各项筛选。

自动筛选已结束课程
选课列表默认隐藏官网明确已结课或课程结束时间已到的课程，可切换“显示全部课程”或“仅看已结束课程”。
目前读取学堂在线课程状态、MOOC 课程期结束日期、智慧树智慧课程结束日期；其他课程结束信息不足时继续显示。
筛选保留历史任务与原有同步选择；需要停止某门已结束课程同步时，显示全部后取消勾选并保存。
全选、全不选只作用当前筛选后的列表，隐藏课程的勾选保留；左侧显示隐藏数量及课程判断原因。
刷新成功取得该课程的新信息，且已续期、重新开课或本轮结束信息不明时，会按最新依据恢复显示。
刷新失败或该课程未出现在本轮目录时沿用上次信息，可切换“显示全部课程”核对。

扫码后怎么看结果
官网尚未确认登录、保存失败、课程或任务范围不完整时，程序留在当前页解释原因及下一步。
“官网仍要求登录”：核对官方 App 授权、验证码和应用内官网返回，再检查接入。
“登录已确认，保存未完成”：检查应用数据目录权限和存储空间后重试。
“登录已确认，课程读取未完成”：登录有效，课程接口或分页未完整读取；按提示重试，无需立即重新登录。
“已接入，任务同步未完成”：部分范围未完整读取，已经读到的任务和人工修改会保留，可稍后重试同步。
网络、超时、官网限制请求、权限、额外验证、页面加载和未知返回分别给出原因及下一步。
仅扫描二维码、打开首页或存在 Cookie 不能证明接入成功。
“接入检查详情”显示本轮时间、计数、结果类别和安全诊断编号。
离开页面后，旧检查结果不会把当前操作强制切回首页。

保存记录与切换版本
右上角 × 隐藏到托盘。切换版本前，请在已运行的程序首页点击“退出程序”，等待登录保存完成。
本程序使用单实例保护，独立测试入口也需要先退出已运行的版本。
安装版默认数据目录为 %LOCALAPPDATA%\LearningTaskAggregator\.local。
普通便携入口与安装版共用当前 Windows 用户的数据；覆盖安装和卸载会保留该外部目录。
便携包内“启动独立测试.cmd”使用“独立测试数据”目录，首次使用为空，可独立登录体验。
需要重新登录时，使用该平台的清理入口并确认；清理保留任务、选课及人工标记。
同一 Windows 用户可在安装时导入旧项目记录；导入前须完整退出旧程序。
Cookie 和受保护任务入口不能直接迁移到其他 Windows 用户或 Android。

本轮范围
八个启用平台统一使用主窗口导航，FiF 保留手动和历史任务。
保留 1.1.5 的学习通作业／考试独立读取及接入失败解释。
U 校园 AI 版在 Windows 仍仅支持手动记录，完整自动任务采集尚未接入。
本轮 Windows 与 Android 同为 1.1.7 筛选与导航测试版；Android 内部版本号 8。
本包为本地测试版。自动检查使用独立数据库、隔离网页登录环境和合成响应。
真实扫码授权、验证码、长期登录、官网最终任务页及实际显示效果仍需本人体验核对。
验证报告、第三方许可及 SHA256 清单随包提供。
