# Windows 依赖许可原文

`Apache-2.0.txt` 固定保存 Apache Software Foundation 的完整原文，供 SQLitePCLRaw 随包交付。来源：https://www.apache.org/licenses/LICENSE-2.0.txt；读取日期：2026-11-07；SHA256：`cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`。

其他依赖的许可、NOTICE 和 NuGet 元数据由 `scripts/collect-windows-licenses.py` 从本机已还原的对应版本包中收集到发布输出的 `ThirdParty`。该脚本按实际 `AccessProbe.deps.json` 收集，发现未处理的新依赖时停止打包。
