聚合平台 Windows 1.1.5 接入体验测试版

支持 Windows 10/11 64 位，.NET / WindowsDesktop 10.0.13 已随包提供。
系统没有 Microsoft WebView2 时，安装向导会联网安装。
Windows 与 Android 各自保存本人的登录、选课和任务，每个平台使用一份当前登录。

开始使用
1. 在首页选择平台，进入课程管理，再点击“连接平台”。
2. 在接入窗口右侧官网完成登录；扫码后需在官方 App 确认授权，再等待官网返回。
3. 左侧接入卡会自动检查，也可点击“我已扫码，检查接入”。
4. 接入卡显示官网登录、课程列表和任务读取的进度；检查成功后点击“选择课程并同步”。
5. 勾选要记录的课程，点击“保存选择并采集”；后续使用“同步已选课程”。
6. 首页汇总各平台任务，点击名称或“打开官方任务”进入官网；答题与提交在官网完成。

扫码后怎么看结果
“已接入，待选择课程”：登录和完整课程列表已确认，下一步选择需要同步的课程。
“已接入，官网当前没有课程”：本轮完整返回空列表，可在课程管理点击“刷新课程”复核。
“登录已确认，课程读取未完成”：官网身份已确认，课程服务读取失败；按提示处理后重试。
“已接入，任务同步未完成”：部分已选范围读取失败，已读取的任务和个人修改会保留。
“官网仍要求登录”：官网尚未认可本应用的当前登录，检查授权确认、验证码和官网返回。
网络、超时、官网限制请求、权限、额外验证、页面加载和未知返回分别给出原因及下一步。
仅扫描二维码、打开首页或存在 Cookie，都不能证明已接入。
左侧“接入检查详情”可展开查看本次检查时间、计数、诊断编号和结果类别。
详情独立滚动，官网保留完整高度；检查成功后保留结果和页面，可自行继续或关闭窗口。

保留登录与记录
重新打开接入窗口会保留现有登录；本人确需重新登录时点击该平台的清理入口。
清理本平台登录保留任务、选课和个人标记；重新登录后仍需官网确认当前身份。
安装版默认数据在 %LOCALAPPDATA%\LearningTaskAggregator\.local。
普通便携入口与安装版共用当前 Windows 用户的数据，覆盖安装和卸载会保留此目录。
独立测试入口使用包内“独立测试数据”目录，首次使用为空，不读取原有任务和登录。
同一 Windows 用户可以安装时导入旧项目记录；导入前在旧版首页点击“退出程序”。
Cookie 和任务入口按当前 Windows 用户加密，不能直接转移到其他用户或 Android。

切换版本
右上角 × 只隐藏到托盘。启动本版前在旧版首页点击“退出程序”，等待登录保存后再切换。
即使选择独立测试入口，也需退出已运行的版本；程序仍使用单实例保护。

本轮范围
已整合最新 PR 的学习通作业和考试独立读取修复，一类失败时保留另一类结果并显示未完成。
八个平台接入窗口提供一致的阶段、失败原因和下一步；FiF 暂不启用。
U 校园 AI 版在 Windows 仍仅支持手动记录，Android 身份与概要预览不等于完整自动同步。
未知结构、未完成分页或登录失效不能当作没有课程或没有任务；人工修改优先保留。
本包为本地测试版。自动验收使用独立数据及合成响应；真实扫码、验证码、长期会话、
官网最终任务页和目视验收由本人继续核对。验证报告、第三方许可和 SHA256 清单随包提供。
